# B. Перечень обрабатываемых полей

**Для юриста · HEYS · главный документ пакета · сверка 11.08.2026**

По каждому полю: где заполняется, тип, обязательность, доступ, внешние сервисы,
срок хранения.

**Срок хранения (общая база, если не указано иначе):** до удаления аккаунта /
отзыва соответствующего согласия; доказательства согласий — 3 года после отзыва
(политика конфиденциальности). Предтриальная анкета при отказе — 30 дней.
Платежи — по налоговым срокам (~5 лет). Резервные копии — отдельно, см. F.

**Кто имеет доступ (если не указано иначе):** клиент (свои данные) и назначенный
куратор; оператор как администратор. Сейчас куратор = оператор.

**Внешние сервисы:** «нет» = остаётся в HEYS / Yandex Cloud РФ. Исключения
названы явно.

**Минимизация анкеты (решение 11.08):** медицинские вопросы из анкеты решено
убрать; код написан 11.08, **миграции на прод не применены** — в таблице ниже
помечено «до минимизации / устарело» и дана актуальная секция.

## Свободный ввод — отдельный список

Это поля, куда человек может напечатать **произвольный текст**, в том числе
сведения о здоровье, диагнозах, самочувствии. **Одно незакрытое такое поле
возвращает режим специальной категории**, даже если структурированные медполя
убраны из анкеты.

| Поле                                                                                   | Где                      | Кто пишет              | Сейчас в продукте                                     |
| -------------------------------------------------------------------------------------- | ------------------------ | ---------------------- | ----------------------------------------------------- |
| **Комментарий к дню** (`dayComment`)                                                   | Дневник / оценки дня     | клиент или куратор     | **да, открытый текст**                                |
| **Заметка о сне** (`sleepNote`)                                                        | Чек-ин / сон             | клиент                 | **да, открытый текст**                                |
| **Комментарий к тренировке**                                                           | Дневник тренировок       | клиент / куратор       | **да**                                                |
| **Переписка с куратором**                                                              | Чат                      | клиент и куратор       | **да, основной канал свободного текста**              |
| **Расшифровка голосового**                                                             | Чат (после SpeechKit)    | система ← речь клиента | **да, по смыслу свободная речь**                      |
| Детали в анкете: хронические состояния, лекарства, травмы, аллергии, ограничения врача | Предтриальная анкета     | кандидат               | **да** (решено убрать вместе с медблоком)             |
| Добавки                                                                                | Дневник                  | клиент / куратор       | **да, свободный ввод** (решено — закрытый справочник) |
| Заметка о дискомфорте (тренировочные модули)                                           | Модули тренировок        | клиент                 | **да**, лимит длины                                   |
| Заметки в модуле «пальцы» и аналогичных                                                | Тренировочные экраны     | клиент                 | **да**                                                |
| Внутренняя заметка куратора по заявке                                                  | Панель решения по анкете | куратор                | **да** (не видна клиенту)                             |

**Не свободный ввод (для контраста):** шкалы настроения/стресса, граммы
продуктов из справочника, вес, время сна, select-статусы без текстового
уточнения.

### Вывод для юриста (по этому списку)

Пока открыты комментарий к дню, заметка о сне и переписка — специальная
категория может появиться в данных **независимо от состава анкеты**. Решение
владельца: либо закрыть/ограничить эти поля, либо принять спецкатегорию и
соответствующую форму согласия; «убрали из анкеты» само по себе вывода не даёт.

---

## Что сознательно не уходит во внешние сервисы

- Содержимое дневника и чек-ина
- Тексты переписки и фото (кроме выбранного клиентом мессенджера)
- Ответы анкеты
- Клиентские данные в зарубежные LLM

Исключение по голосовым: только Yandex SpeechKit при отдельном согласии.
