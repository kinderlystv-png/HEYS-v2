### Проверка по циклу (шаг 1, может снять объём у юриста)

Кодер заполняет `lawyer-cycle-device-check.md` по
[`prompt-lawyer-package-2`](../%20release/handoff-prompts.md) §1 — **три слоя:**

| Слой     | Содержание                                                                                                                                     |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| **§1.1** | Счётчик `cycleDay` в **прод-БД** (read-only SQL); если **0** → «миграция при device-only не нужна»                                             |
| **§1.2** | Четыре условия юриста — только статусы **гипотеза → проверено**; вывод для юриста из проверенного                                              |
| **§1.3** | При четырёх «да» — обязательная **смета device-only** (файлы, S/M/L или дни, продуктовая цена, данные, риски) для выбора переделка vs паспорта |

- Если **даты не покидают устройство** (есть «нет» в §1.2) — блок цикла выходит
  из-под ст. 10.
- **По первым признакам все четыре «да»** — тогда смета §1.3 и решение
  владельца: переделка vs паспортные реквизиты.

## 2. Блок G — статус вложения

|                |                                                                                                                                                                                                                                                                                                      |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Статус**     | **Не найден** (11.08.2026)                                                                                                                                                                                                                                                                           |
| **Что искали** | PDF или полный скан **поданной формы изменений** (updateform) от **17.06.2026** — все страницы с заявленными целями, категориями субъектов, перечнем ПДн, спецкатегорией «здоровье», действиями, трансграничкой. Редакция после публикации приказа **№ 131 от 24.07.2026**, запись **26-22-005319**. |
| **Где искать** | Внешний архив оператора (по [`22` §1.7.3](../маркетинг/22_План_реализации_маркетинга.md) должен был сохраниться 17.06) → почта после ЕСИА → ЛК [pd.rkn.gov.ru](https://pd.rkn.gov.ru/operators-registry/notification/)                                                                               |

### Что **не** подходит за блок G

| Артефакт                                                                                                               | Почему не годится                                                                                             |
| ---------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| Письмо о **первичной регистрации** оператора (2022, приказ № 188)                                                      | Другая цель: кадры/бухгалтерия. HEYS туда не входит. Юрист сверяет **текущую** запись после изменений 2026 г. |
| Автоуведомление «запись внесена» / «принято на портале» без тела формы                                                 | Нет перечня полей и формулировок целей — нельзя сравнить с [B](./lawyer-B-fields.md)                          |
| Только номер записи в теме письма                                                                                      | То же: нет содержания уведомления                                                                             |
| Рабочая копия в репо ([`rkn-notification-heys-working-copy.md`](./lawyer-G-rkn/rkn-notification-heys-working-copy.md)) | Черновик для подачи, не доказательство того, что ушло в реестр; юристу нужна **официальная** картина          |

**Карточка оператора из публичного реестра** — скрин или экспорт страницы записи
**26-22-005319** (поиск по ИНН **263517141102** на
[pd.rkn.gov.ru/operators-registry/](https://pd.rkn.gov.ru/operators-registry/)).
Это юридически видимое регулятору состояние после приказа 131.

В репо уже есть: сводка
[lawyer-G-rkn-notification.md](./lawyer-G-rkn-notification.md), рабочие тексты
полей, статус по [`31`](../маркетинг/31_РКН_уведомление_ПДн_ИП.md). PDF формы —
**дополнение**, если позже найдётся в архиве.

## 4. После ответа юриста → версия 1.11

Один пакет правок, один цикл переподписания. Входит не только ответ юриста, но и
уже принятые решения:

- проактивность куратора в оферте;
- границы Pro Спорт;
- возрастной ценз;
- срок действия согласий;
- реквизиты оператора (H) и соглашение о ПЭП;
- правки из построчного разбора C.

Точечные правки 1.10 без bump версии **не делаем** — иначе два цикла
переподписания.

## 5. Завтра: если начинать с кода, а не с юриста

**Login первым.** Обход legacy (`verify_client_pin_v3` без `access_code_hash`)
**уже в проде** — единственный срочный фикс, который не закрывается документами.

| Действие | Деталь                                                                                               |
| -------- | ---------------------------------------------------------------------------------------------------- |
| Коммит   | Исходники login/ПЭП по [`release-plan` A3](../%20release/release-plan.md)                            |
| Staging  | Прогон сценариев входа                                                                               |
| Прод     | Применить то, что ещё не в проде                                                                     |
| Деплой   | **`heys-api-rpc`**, **`heys-api-auth`**, **`heys-cron-reminders`** — ждёт команды владельца (см. A3) |
| Фронт    | Подключение экранов «Вход v4» — следом за деплоем API                                                |

Промпты: [`prompt-login-server`](../%20release/handoff-prompts.md). Юридический
пакет и login **можно параллелить** разными исполнителями.
