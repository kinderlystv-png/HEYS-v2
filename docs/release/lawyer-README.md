## Опорные факты для всего пакета

1. Передачи клиентских ПДн за границу нет.
2. Функция `heys-mcp` из прода удалена (11.08.2026); автодеплой выключен.
3. Уведомление в РКН о трансграничной передаче не подаётся.
4. Главный юридический рычаг по спецкатегории — документ **B**, блок свободного
   ввода.
5. Без **C** и опубликованной **карточки реестра (G)** разбор неполный: тексты и
   заявленное в реестре — половина работы юриста.
6. К письму от владельца: **скрин карточки оператора из реестра** (PDF поданной
   формы пока **не найден** — см. [lawyer-workflow.md](./lawyer-workflow.md) §2)
   и живые скрины экранов согласий (C).
