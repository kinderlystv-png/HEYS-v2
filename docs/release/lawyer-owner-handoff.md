## 1. Блок G — PDF формы не найден

### Статус

**Не найден** (зафиксировано 11.08.2026). Внешний архив и почта пока не дали
пригодного файла.

### Что именно ищем (если будете копать дальше)

|                |                                                                                                                                                                    |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Нужно**      | PDF или сканы **всех страниц** формы **«Уведомление о внесении изменений в сведения в реестре»** (updateform), поданной **17.06.2026** через ЕСИА                  |
| **Содержание** | Полный текст заявленных целей (в т.ч. HEYS), категорий субъектов, перечня ПДн, спецкатегории «здоровье», действий, «трансграничная передача — нет», места хранения |
| **Редакция**   | После публикации приказа **№ 131 от 24.07.2026**, не первичная регистрация 2022 г.                                                                                 |
| **Где**        | Архив оператора → письма от pd.rkn.gov.ru / Госуслуг после подачи → ЛК [pd.rkn.gov.ru](https://pd.rkn.gov.ru/operators-registry/notification/)                     |

### Почему **письмо о регистрации** не подходит

| Письмо / файл                                                     | Почему не блок G                                                        |
| ----------------------------------------------------------------- | ----------------------------------------------------------------------- |
| Уведомление о **первичной** регистрации 2022 г. (приказ № 188)    | В записи только кадры, бухгалтерия, договоры с физлицами — **без HEYS** |
| «Запись внесена» / «принято на портале» **без приложенной формы** | Нет перечня полей — юрист не сверит с [B](./lawyer-B-fields.md)         |
| Только номер **26-22-005319** в теме                              | Нет содержания уведомления                                              |

Юрист сверяет **что заявлено в реестре** с **что реально собираете**. Для этого
нужны либо PDF поданной формы, либо **карточка из публичного реестра** (см.
ниже).

### Что отдаём юристу сейчас (вместо PDF)

**Скрин карточки оператора** с
[pd.rkn.gov.ru/operators-registry/](https://pd.rkn.gov.ru/operators-registry/) —
поиск по **26-22-005319** или ИНН **263517141102**. Это опубликованное после
приказа 131 состояние; для сверки с B его достаточно как минимум.

В репо для юриста уже лежат:
[lawyer-G-rkn-notification.md](./lawyer-G-rkn-notification.md),
[рабочая копия полей](./lawyer-G-rkn/rkn-notification-heys-working-copy.md),
канон [`маркетинг/31`](../маркетинг/31_РКН_уведомление_ПДн_ИП.md).

PDF — приложить позже, если найдётся; в git не кладём
([`32` §1.1](../маркетинг/32_ПДн_governance_релизный_контур.md)).

(`prompt-lawyer-package-2`):

1. Письмо — шаблон **`prompt-lawyer-2`** в
   [handoff-prompts.md](../%20release/handoff-prompts.md).
2. Папка `docs/release/lawyer-*`.
3. Вложения от вас: **карточка реестра** + **скрины C**.
4. Ответ юриста — **один документ** с правками → пакет **1.11** (см.
   [lawyer-workflow.md](./lawyer-workflow.md) §4).
