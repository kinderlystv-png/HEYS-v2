  очередь модерации будет забиваться одинаковыми продуктами с чуть разными
  цифрами, и куратор будет разбирать это руками каждый раз. Проверить, по чему
  считается дубль _— до 18.08_
- ⬜ **Поле телефона просит 10 цифр после +7, а не 11.** Ввод `78888888888`
  превращается в `77888888888` и вход не проходит. Ловушка того же класса, что
  мусорные номера у тестовых клиентов: поле молча принимает неверное и отдаёт
  ошибку про код. Проверить, что вставка полного номера из буфера обрабатывается
  корректно — люди копируют номер целиком _— до 18.08_

  **Форма отчёта — строка на пункт.** Прогон засчитывается только в этом виде:

  лучше зачёта по моку.

  ```
  диалог Escape — Выйти: …
  модерация pending: …
  модерация exists: …
  модерация pending_dup: …
  модерация offline: …
  invalid_session: пропущен / …
  harm (не toast): …
  фото на граммах: …
  провалы на пути: … / нет
  заявки модерации отклонены: …
  приёмы у тестового клиента: …
  ```
