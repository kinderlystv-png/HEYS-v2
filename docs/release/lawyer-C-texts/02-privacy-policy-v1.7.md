## 3. Основания и специальные категории

Обычные данные обрабатываются на основании отдельного согласия, для заключения и
исполнения договора, исполнения обязанностей оператора и обеспечения
безопасности в случаях, предусмотренных законом.

Сведения о здоровье и фактически раскрывающие здоровье данные обрабатываются
только при наличии отдельного действующего согласия на обработку данных о
здоровье. До такого согласия чтение и запись health-data в HEYS блокируются.

Маркетинговые сообщения, автоматическая расшифровка SpeechKit и Яндекс.Метрика
необязательны и требуют отдельных действий пользователя. Отказ не лишает доступа
к основному сервису, кроме функции, для которой данные нужны.

## 4. Цели и действия

HEYS собирает, записывает, систематизирует, хранит, уточняет, извлекает,
использует, передаёт указанным обработчикам, обезличивает, блокирует и удаляет
данные для:

1. обработки заявки, создания аккаунта и исполнения договора;
2. ведения дневника и безопасного сопровождения назначенным куратором;
3. работы защищённого чата, загрузки фото и голосовых сообщений;
4. расчётов, чеков, отмены и возврата;
5. поддержки, информационной безопасности, аудита и исполнения запросов;
6. аналитики лендинга и маркетинга — только при отдельном согласии.

| Yandex SpeechKit / структуры Яндекса         | выбранное аудио и технические данные для расшифровки — только по согласию версии 1.1     |
| ЮKassa / НКО «ЮMoney»                        | платежи, возвраты и данные для кассового чека; HEYS не хранит данные банковской карты    |
| Telegram и иной выбранный внешний мессенджер | связь по заявке или сообщения, которые пользователь сам направляет через этот канал      |
| Яндекс.Метрика / ООО «Яндекс»                | аналитика лендинга только после выбора «Разрешить»; Webvisor отключён                    |

HEYS не продаёт данные, не передаёт их брокерам данных и не использует сторонние
рекламные пиксели.

Первичная запись и хранение персональных данных граждан РФ выполняются в
информационных системах на территории России. При выборе внешнего мессенджера
его инфраструктура может находиться за пределами РФ; пользователь сам выбирает
этот канал. Любая иная трансграничная передача допускается только после
выполнения применимых требований статьи 12 152-ФЗ.

## 6. Сроки и удаление

| Данные                                                                        | Срок / событие прекращения                                                                                                            |
| ----------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| Заявка                                                                        | до достижения цели, отзыва согласия или применимого срока операционного учёта                                                         |
| Аккаунт, профиль, дневник, сообщения, фото, аудио и расшифровки               | до удаления аккаунта/контента, отзыва применимого согласия или прекращения цели                                                       |
| Отклонённая предтриальная анкета                                              | 30 дней после отказа, затем удаление по регламенту                                                                                    |
| Доказательства согласий (в т.ч. журнал подписания и тексты версий документов) | 3 года после отзыва либо дольше при текущем споре/обязанности доказать согласие; удаление иных данных субъекта этот срок не сокращает |
| Платёжные и кассовые документы                                                | в сроки, обязательные по бухгалтерскому и налоговому законодательству                                                                 |
| Технические журналы                                                           | по утверждённому операционному сроку, необходимому для безопасности и аудита                                                          |
| Резервные копии                                                               | по отдельному циклу хранения; удалённые данные исчезают из них по мере ротации                                                        |

После подтверждённого запроса HEYS прекращает обработку и удаляет либо
обезличивает данные в сроки и случаях, предусмотренных 152-ФЗ, кроме сведений,
которые оператор обязан или вправе хранить по иному законному основанию. Отзыв
health-consent запускает блокировку и удаление health-data по действующему
регламенту; отзыв SpeechKit прекращает новые расшифровки.

## 7. Защита и доступ

Применяются HTTPS, контроль доступа, аутентифицированные сессии, шифрование
health-data и защищённой анкеты, журналирование доступа, резервное копирование и
разделение клиентов. Куратор видит только назначенных ему клиентов. Подменный
куратор получает временный доступ после назначения и связан теми же
обязанностями конфиденциальности; доступ отзывается после окончания подмены.

## 8. Права пользователя

Пользователь вправе запросить сведения об обработке и копию данных, потребовать
уточнения, блокирования или удаления, отозвать отдельное согласие, возразить
против необязательной обработки и обратиться в Роскомнадзор или суд.

Запрос направляется на **poplanton@mail.ru**. HEYS вправе запросить разумные
сведения для подтверждения личности и защиты данных от выдачи постороннему.
