## 3. Перечень персональных данных

Обработке подлежат:

- имя, номер телефона, адрес электронной почты, выбранный мессенджер и
  идентификатор в нём, идентификатор учётной записи;
- год рождения, пол, рост, вес, цели по питанию;
- сведения о приёмах пищи, продуктах, весе порций, калорийности и составе
  белков, жиров и углеводов, о потреблении воды;
- сведения о продолжительности сна и его субъективной оценке;
- сведения о физической активности, шагах и тренировках;
- субъективные оценки самочувствия, настроения и уровня стресса по шкале;
- сообщения, фотографии и голосовые сообщения, направленные мной в чате сервиса,
  и полученные расшифровки;
- сведения о заявке: источник перехода, промокод, метки перехода, комментарии;
- платёжный идентификатор, сумма, тариф и статус платежа, сведения для кассового
  чека;
- технические данные: IP-адрес, сведения о браузере и устройстве, данные сессии,
  события безопасности, версии и доказательства данных мной согласий.

Обработка сведений, относящихся к специальным категориям персональных данных,
настоящим согласием не охватывается и Оператором не осуществляется.

Подключение отдельных функций сервиса, для работы которых требуются иные данные,
выполняется по моему выбору на основании отдельного согласия.

## 4. Перечень действий и способы обработки

Оператор вправе совершать с указанными данными следующие действия: сбор, запись,
систематизация, накопление, хранение, уточнение (обновление, изменение),
извлечение, использование, передача указанным в разделе 5 лицам, обезличивание,
блокирование, удаление, уничтожение.

Обработка осуществляется смешанным способом — с использованием средств
автоматизации и без них, с передачей данных по сети Интернет. Первичная запись и
хранение данных осуществляются в информационных системах на территории
Российской Федерации.
