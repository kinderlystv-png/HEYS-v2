## Протокол владельца

Во время решений не открывать документацию, диагностику и технический лог.
Наблюдение состоит из двух прохождений одного зерна:

1. Самостоятельно пройти первую неделю до карточки «Неделя завершена».
2. На итоговой карточке выбрать «Пройти этот сценарий иначе».
3. Во втором прохождении заранее назвать другую стратегию и играть по ней до
   первой наблюдаемой downstream-разницы, затем закончить неделю.
4. Сброс «Начать заново» из верхнего меню проверить отдельно: он создаёт новый
   сценарий и потому не является evidence same-seed replay.

Во время прохождения фиксируются только фактические проблемы уровня S0/S1.
Остальные оценки заполняются после второго итога, чтобы вопросы не подсказывали
механику.
