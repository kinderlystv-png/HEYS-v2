# Гейт дрейфа контракта возвращён в рабочее состояние (2026-08-31)

**Что было.** `node scripts/ui-v4-check-contract-drift.mjs` падал в 11 зонах
из 20. Причина везде одна: пакет дизайна 30 августа добавил в каждый канвас
раздел «Разбор кадров · элемент за элементом», и эти строки контракта пришли без
вердиктов. Красный гейт в таком виде бесполезен — он не отличает «приехал новый
разбор» от «дизайнер переписал строку, по которой сведён экран», и следующую
правку пакета никто бы не заметил.

**Что сделано.** Отпечатки пересняты во всех одиннадцати зонах
(`--rehash <зона>`), после чего 149 строк разбора подняты с `?` до `=` — это
ровно те, что реально сверяются парами «элемент кадра → правило продукта» в
тестах сверки.

## Почему пересъёмка здесь безопасна

Пересъёмка переставляет отпечаток **всем** строкам зоны, в том числе изменённым,
сохраняя их прежний вердикт. Это её опасная сторона: правку дизайнера в строке,
по которой экран уже сведён, она бы молча одобрила.

Поэтому перед пересъёмкой проверено, что в выводе гейта нет ни одной строки
«дизайнер изменил строки контракта, вердикт не пересмотрен» и ни одной «вердикт
есть, а строки в контракте больше нет» — только «новые строки контракта без
вердикта». Изменённых строк не было ни в одной из одиннадцати зон: все они
разобраны по ходу этих двух дней, каждая своим заходом.

## Что теперь показывает `--list`

|                            | строк  |
| -------------------------- | ------ |
| всего                      | 12 067 |
| `=` сведено                | 4 287  |
| `?` никто не смотрел       | 6 437  |
| `≠` осознанное отступление | 281    |
| `—` к коду не сводится     | 1 062  |

`?` — это честный долг, а не забытая команда: раздел разбора даёт по сотне строк
на зону, и покадрово он разобран только там, где стоят гейты сверки. Долг виден
в `--list` и уменьшается заходом по кадрам, а не пересъёмкой.

## Что гейт ловит теперь

- дизайнер переписал строку, по которой экран сведён, — «вердикт не
  пересмотрен»;
- дизайнер добавил строку — «новые строки контракта без вердикта»;
- дизайнер удалил строку, а вердикт остался, — «вердикт есть, а строки нет».

До пересъёмки все три тонули в общей красноте.

## Что подняли до `=`

149 строк разбора в девяти зонах: советы 47, геймификация 23, вход 21, дата 20,
настройки 15, знак ожидания 9, питание 8, цикл 6, кураторские правки 3. У каждой
в вердикте назван файл сверки, который её держит: строка разбора читается из
самого канваса, поэтому расхождение всплывает при правке любой из сторон.

Список выведен из самих тестов, а не из памяти: ключи собраны разбором таблиц
пар и проверены против снимка — все 152 нашлись, промахов ноль.
