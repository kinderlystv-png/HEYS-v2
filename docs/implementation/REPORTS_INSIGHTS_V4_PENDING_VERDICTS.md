# Вердикты reports-insights, ждущие посадки раскола снимка

Пока `docs/ui/verdicts/*.json` не закоммичен, вердикты не пишет никто — решение
дирижёра сведения макетов от 31 августа. Разобранное копится здесь и
проставляется одним заходом после посадки.

Формат строки: `ключ · вердикт · факт`.

## Проставлены (были в ожидании)

| Ключ строки контракта                 | Вердикт | Факт                                                                                                                                                                                                            |
| ------------------------------------- | ------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `формат · дата и оценка в ленте дней` | `=`     | «сб · 8 авг» без точки сокращения и без года, оценка через дробь `dayScore + '/10'`; метка проверяется исполнением функции на всех двенадцати месяцах — `reports-v4-formats.test.js`                            |
| `формат · вес и его подпись`          | `=`     | подпись «Вес · 30 дней», значение 21/800 моноцифрами с запятой и «кг» после числа, Δ за период ролью `--v4-ok-text` без повтора единицы; собрана из `weightTrend.diff`, прежний бейдж с эмодзи в v4 не рисуется |
| `состав · факторы каскада Score`      | `=`     | `CRS_SCORE_GROUPS` в `heys_cascade_card_v1.js` — ровно четыре, порядок Питание · Сон · Активность · Ведение задан списком, сортировки по значению рядом нет                                                     |

было 162/8/9/834 на коммите `94d6301a4`, перенесено расколом в

переезда файла, а не от расхождения с макетом.
