## Шаги

1. `HEYS.push.setEnabled` — клиент: согласие 1.2, затем subscribe; выкл:
   unsubscribe, затем отзыв. Куратор: только устройство.
2. Тумблер сверху листа настроек. В шапку колокольчик не возвращать.
3. Карточка, баннер первого дня, онбординг, отзыв в журнале согласий — тот же
   API. Второй выключатель в «Мои согласия» убрать.
4. Клиенты с кодом доступа: `setPushConsent` → `needsAccessCode` → PIN-шторка в
   push-настройках → `signConsentsWithAccessCode` с `/docs/v1.2/…`.
