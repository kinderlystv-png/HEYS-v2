# Протокол: лист «куратор обновил дневник» v4

**UI-гейт:** цель — показать правки куратора, не отбирая управление; главное
действие — «Понятно»; слой 1 — шапка, раскрытый свежий день, «Позже» /
«Понятно»; слой 2 — свёрнутые дни, хвост дат, продукты после трёх, точка на
«Питании», строка входа в дне; критическое не скрывать — после двух показов
правки остаются достижимы точкой или строкой дня, после «Понятно» строка дня
остаётся входом перечитать; на «Питании» в чужой дате строка текущего дня ведёт
к правленой дате (точка на активной вкладке по-прежнему скрыта).

Источник: канвас `docs/ui/handoff-v4/canvas/Регистрация и чек-ин v4.dc.html`
(кадры листа + «Точка вместо листа» + «Вход внутри вкладки»).

## Шаги

1. Лист снизу, не карточка по центру. «Понятно» подтверждает показанное и никуда
   не уводит. Строка ведёт в дневник/актив, шеврон, без «Показать».
2. Ack записи — когда по ней не осталось видимых строк или нажали «Понятно». Тап
   по строке прячет её локально на сессию.
3. Шапка даты: первое «было» → последнее «стало» среди неподтверждённых записей
   дня. Нет полей — шапка без ккал (легально, кадр «Без еды»).
4. После двух автопоказов за сессию третий лист не приходит: точка 7 px на
   «Питании», без счётчика. Уже на «Питании» точка недостижима — строка «Куратор
   обновил этот день» в шапке дня открывает тот же лист, отфильтрованный датой.
   Она же — возврат после «Понятно».
5. Не ждать деплоя `day_kcal_*`: верстать на фолбэке.
