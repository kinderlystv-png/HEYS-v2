# Протокол: утренний чек-ин v4

**Дата:** 2026-08-16 (§4 пачки — 2026-08-17; §7 сверка с канвасом —
2026-08-19)  
**Canvas:** `docs/ui/handoff-v4/canvas/Переработка дизайна приложения/design_handoff_heys_v4/checkin-morning.v4.dc.html`
(33 экрана, `data-screen-label`)  
**Статус:** ритуал v4 локально собран; §4 пачки — канвас и код `YesterdayVerify`
согласованы (смоук `yesterday-verify-v4-pack.test.js`); push/deploy не входят

## UI-гейт

`цель — закрыть утро пятью экранами; главное действие — Дальше / Готово; слой 1 — вопрос и первичная кнопка; слой 2 — заметка сна, тип холода, замеры, курс добавок; критическое не скрывать — пропуск веса пишет расчётный, не измеренный.`

## Инварианты

- Одна поставка всего ритуала. Регистрация уже сплитирована и не переделывается.
- Экран «Записано» и правило «не взвешивался» — один смысл: кадр
  `checkinRecorded` не подключать без `weightMorningSource`.
- `weightMorningSource`: `measured` | `estimated_avg` | `estimated_profile`.
- Estimated не кормит `getLastKnownWeight` и тренд.
- Серия дня растёт на расчётном весе. **Отметки в истории серии в этой поставке
  нет нигде** — лучше без неё, чем в одном экране есть, а в другом нет.

## Крупные шаги

### 1. Хром StepModal — сделано

- Дневной layout: без крестика, первичная кнопка в футере, точки-пилюли.
- `yesterdayVerify` и `checkinRecorded` — `hiddenFromProgress`.
- Регистрация и точечные `showCheckin.*` остаются на старом хроме.

### 2. План экранов — сделано

Полное утро:
`[yesterdayVerify?], weight, sleep, morning_mood, stepsGoal, morningRest, checkinRecorded`.

- `sleep` пишет `sleepStart/sleepEnd` + `sleepQuality` одним ack.
- `morningRest` — пятый обязательный экран до «Готово»: душ/холод, inline-рутина
  **Сделал / Сделаю / Не сегодня** (без шеврона и без интенсивности в чек-ине),
  замеры с просрочкой ≥7 дней, карточка добавок только при непустом курсе (слои:
  курс / пустой / добавление / доза+время), плашка согласия при любом
  недостающем согласии (замеры и добавки раздельно, product-wide snooze).
  Загрузочный день — на шаге `stepsGoal`, не здесь. `morningActivation`:
  `done|planned|skipped`, при `done` без подстановки `intensity`; fallback после
  еды — те же три кнопки, без snooze по приёмам пищи.
- `_dailyRequiredOnly` только reopen пропавших core, не каждое утро.
- Старый ledger `sleepTime`/`sleepQuality`/хвост схлопывается в новые id.
- Точечные входы `showCheckin.sleep` / `.weight` / добавки — старые id.

### 3. Вес — сделано

- «Дальше» — измеренный: `weightMorning` + `profile.weight` + XP.
- «Не взвешивался» — среднее трёх измеренных, иначе профиль. Не трогает профиль
  и XP.
- На «Записано»: измеренный — только норма + шаги и hint про вечер; расчётный —
  строка «Вес дня … · расчётный», серия «… без взвешивания», hint про график.
  Стрелка назад в шапке ведёт на предыдущий шаг (как в canvas). Ккал через
  `TDEE.resolveDailyTargets`.

### 4. Вчера и пачка — сделано (канвас + код)

**Размещение.** `yesterdayVerify` — развилка **до** мастера, без точек прогресса
(`hiddenFromProgress`). Шапка «Перед чек-ином»; мастер начинается с веса.

**Когда показываем (только еда, «или»):** нет приёмов; ноль калорий; меньше
половины нормы дня (`ratio < 0.5`). Нулевые шаги и вода сами по себе вопросом не
становятся.

**Один день** — метка `Чек-ин · вчерашний день`. Четыре выхода:

1. **Дописать точно** — дневник на дату, чек-ин закрывается. Выход идёт через
   `context.onExitToDiary` (29 августа): блокирующий мастер рисуется оверлеем
   без крестика и `onClose` в него не передаётся, поэтому до правки кнопка была
   мёртвой — тап переключал вкладку под оверлеем и на этом всё. Оверлей на
   `exitToDiary` гасит показ и держит `suppressMorningCheckin`, пока человек в
   дневнике; ушёл из дневника — чек-ин возвращается той же развилкой. В обычной
   модалке (`showCheckin.morning`) остаётся прежний `onClose`.
2. **Так и было · {kcal}** — `confirm_real_data`; цифра в кнопке = подтверждение
   факта, без второго диалога. Пустой день: `Так и было · ничего не ел` (не «· 0
   ккал»).
3. **По ощущениям** — слой `Чек-ин · вчера по ощущениям`; четыре силы из
   `QUICK_FILL_PRESETS`: «Не доел», «Как надо», «Скорее переел», «Сильно
   переел»; ккал от нормы того дня; метка «по ощущениям».
4. **Заполню позже** — `fill_later`; утро закрывается, день вернётся завтра.

**Пачка** — метка `Чек-ин · пачка незакрытых дней`. Строка списка нажимается
целиком → `Чек-ин · день из пачки` (не сразу в оценку). Шапка «День N из M»; те
же четыре выхода; «Дописать точно» первым; назад — «К списку дней» без потери
ответов; закрытый день уходит из списка.

- Пустой день в пачке — `Чек-ин · пустой день из пачки`: карточка «записей нет»,
  норма того дня, «шаги и вес · есть, не трогаем»; на экране разведены «ничего
  не ел» (данные) и «Очистить пустые» в списке (убрать без утверждений про еду).

**Два массовых действия — взаимоисключающие; один день не проходит оба:**

| Действие                 | Что делает                                 | После                                                                                                                                                                        |
| ------------------------ | ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Очистить N пустых**    | Только дни без еды; день с ккал не трогает | Пустые ушли; если остались дни с едой — список как `Чек-ин · пачка после очистки`: кнопки очистки нет, bulk-счётчик только по оставшимся («Закрыть оба примерно» и т.п.)     |
| **Закрыть {N} примерно** | Ведёт на `Чек-ин · сила для пачки`         | Одна сила на всю пачку; те же четыре названия, что на одиночном дне; пустые — оценка целиком; где еда есть — **только добор** (640 ккал остаются). После bulk чистить нечего |

Подпись на bulk-экране: если день непохож на остальные — закрыть отдельно из
списка.

**Пресеты.** Один словарь `QUICK_FILL_PRESETS` для одиночного дня и пачки; на
bulk подписи в % нормы дня, на одиночном — в ккал.

**Проверки (целевые):** `yesterday-verify-v4-pack.test.js`,
`morning-checkin-v4-layout-smoke.test.js` — copy, метки, взаимоисключение
очистки/bulk, динамический текст кнопки bulk.

### 5. Канвас-визуал — сделано

Точки `#c67139` 18px, футер без зелёного `.mc-btn--primary`, шкала 26px, вчера
как в канвасе. Смоук: `morning-checkin-v4-layout-smoke.test.js`.

### 6. Шкала цели шагов — сделано

Нелинейный трек 3 000–30 000: норма ~10 000 на ~⅔ шкалы (как раньше
психологически «много»), выше — крупнее шаг (100 / 500). Метка «Совет · N» /
«Старт · N» с числом; тап возвращает совет. Вне совета — терракотовая заливка и
число. Смоук: `adaptive-steps-goal.test.js` + layout-smoke.

### 7. Сверка с канвасом — сделано (2026-08-19)

Пройдены все 33 кадра `data-screen-label`. Расхождения закрыты:

| Экран                | Было                                                                                              | Стало                                                                                                                                                                                                                                                                   |
| -------------------- | ------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Цель по шагам        | опечатка «Сдв**in**ьте пальцем» (латинские `in`) в базовом варианте                               | «Сдвиньте пальцем»                                                                                                                                                                                                                                                      |
| Цель по шагам        | «Загрузочный день» рисовался **после** сноски «План на день…»                                     | строка стоит между подсказкой ползунка и сноской, как в канвасе                                                                                                                                                                                                         |
| Добавки · добавление | в группе «Витамины и микроэлементы» 6 чипов, `iodine` не было в каталоге                          | добавлен `iodine` («Йод», 150 мкг, шаг 25, `withFood`) — 7 чипов как в канвасе                                                                                                                                                                                          |
| Пачка дней           | «Очистить **2** пустых», «считает только эти **2** дня»                                           | числительное словом (`spellPackCount`), как у «Закрыть оба примерно» / «Записать четыре дня»                                                                                                                                                                            |
| Замеры (слой)        | «Прошло **9** дней с прошлых»                                                                     | «Прошло девять дней с прошлых»; строка пятого шага остаётся с цифрой — так в канвасе                                                                                                                                                                                    |
| Все шаги мастера     | верхний отступ контента разный (сон 22px против 14px у остальных) — заголовок прыгал при переходе | один `padding-top: 24px` на `weight / sleep / mood / stepsGoal / morningRest`; «Записано» центрируется как раньше, слои курса добавок держат свою геометрию; отступ расчётного веса переехал из inline-стиля в `.mc-weight-step--estimated`, старый хром сохраняет 34px |

Осознанно **не** переносили: на кадре «замеры просрочены» канвас показывает
укороченный текст про душ («Тридцать секунд… — достаточно»). Ставить копирайт
душа в зависимость от просрочки замеров нечем оправдать — это вариативность
канваса, а не правило. Копия душа остаётся одна.

высоты шага отступы дополнительно замерены в браузере — 24px на всех пяти
