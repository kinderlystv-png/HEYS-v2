# Карточка воды в «Разборе дня» — приведение к канвасу v4

Источник правды:
`docs/ui/handoff-v4/canvas/Переработка дизайна приложения/design_handoff_heys_v4/water-add.v4.dc.html`,
блок `[data-contract="water-add"]`, строки 13, 35, 42–52, 55–61, 64. Кадры:
`Вода · карточка · Полоса`, `Вода · карточка · Полоса · утро`,
`Вода · карточка · Кольцо` (все `data-demo="stop"`).

Дата: 2026-08-20. Статус: сделано и подключено в живой экран.

**Поправка по ходу работы.** Сначала карточка была переписана по адресу
`#water-card` из `heys_day_diary_section.js` — но этот блок живёт внутри
`.nutrition-v4-legacy-meals`, у которого `display: none`, да ещё и под
выключенным тумблером `showDiaryWaterPanel`. На экране «Разбор дня» воду рисовал
другой блок — `nutrition-v4-water` в `heys_day_nutrition_v1.js` (подпись, «2 000
/ 3 500 мл», три кнопки). Первый прогон правки поэтому ничего не менял
визуально. Исправлено: карточка подключена в `NutritionTabV4`, legacy-точка и
мёртвый тумблер удалены, добавлен интеграционный смоук, который падает, если
карточка снова окажется не на экране.

## UI-гейт

- цель — показать «сколько выпито сегодня» и дать добавить воду не уходя с
  «Разбора дня»;
- главное действие — ряд объёмов (−200 / +200 / +500, в виде «Кольцо» — +100 /
  +200 / +330 / +500);
- слой 1 — подпись, норма, факт, остаток, полоса за сегодня, неделя, среднее,
  объёмы, переключатель вида;
- слой 2 — тап по факту (в «Кольце» — по кольцу) открывает существующий
  metric-popup: разбор нормы (база / шаги / тренировка) и напоминание «давно не
  пил»;
- критическое не скрывать — норма и факт всегда в первом слое; погашенный −200
  остаётся в ряду.

## Что было

`renderWaterCard` рисовал sky-карточку v2: голубой градиент с рамкой `#bae6fd`,
кольцо 72 px хардкодом `#0ea5e9`, breakdown эмодзи-строкой, мотивация,
напоминание, прогресс-бар с пузырьками и волной, четыре пресета с иконками,
14-дневная кривая, лайфхак. Ни одного элемента канваса v4.

## Что стало

Два вида одной карточки, оба в продукте. Дефолт — **«Кольцо»** (решение
владельца 2026-08-20; канвас в строке 44 ставит дефолтом «Полосу», расхождение
зафиксировано в листе приёмки вердиктом `≠`):

| Вид    | Состав                                                                                                                                                                                                                                                                    |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Полоса | подпись «Вода» + «из N л» · факт 26 px/600 с единицей и остатком · полоса 6 px глубоким тоном · неделя семью столбиками (дорожка 30 px, сегодня всегда правый, прошлые — средний тон ramp, сегодняшний — глубокий) · подвал: «в среднем N л» слева, −200/+200/+500 справа |
| Кольцо | подпись «Вода · 7 дней в среднем N л» + −200 справа · кольцо 58 px доли нормы, факт и «из N · осталось M» · четыре объёма +100/+200/+330/+500 · неделя кривой с заливкой 16 %, пунктиром нормы, залитыми/контурными точками и ореолом сегодня                             |

Переключатель — две пилюли **под карточкой, слева, без подложки и разделителя**
(решение владельца 2026-08-20: внутри карточки ряд мешал оценивать данные;
канвас ставит его справа над линией), 26 px, 10/600, тач-цель 44 pt, запись
сразу по нажатию в `localStorage` (`heys_water_card_view_v1`, суффикс clientId),
без облака.

Подложка карточки — `--v4-surface` (совпадает с канвасом во всех четырёх
палитрах: `#f7efe2` / `#23201b` / `#eef3f9` / `#182a3a`); рамка, радиус и тень
остаются от карточек дневника.

## Шаги

1. `apps/web/heys_day_water_v1.js` — карточка переписана компонентом
   `WaterReviewCard`; добавлен `HEYS.dayWater.applyOptimistic` — один DOM-апдейт
   числа, остатка, полосы, сегодняшнего столбика, кольца и состояния чипа −200.
2. `apps/web/styles/modules/400-water-and-hydration.css` — блок `.water-review*`
   по геометрии канваса, токены на 4 палитры (`--wr-*`); мёртвые правила старой
   карточки удалены (−860 строк вместе с тёмным блоком).
   `000-base-and-gamification.css` — два правила переведены с `.compact-water`
   на `.water-review`.
3. `apps/web/heys_day_day_handlers.js` — оптимистичное обновление переведено на
   `applyOptimistic` (раньше две копии DOM-кода по селекторам кольца). 3a.
   `apps/web/heys_day_nutrition_v1.js` — блок `nutrition-v4-water` заменён
   вызовом `HEYS.dayWaterCard.buildWaterCard`; `heys_day_nutrition_card_v1.js` и
   `heys_day_tab_impl_v1.js` прокидывают `waterGoalBreakdown`, `waterLastDrink`,
   `openExclusivePopup`. 3b. Удалены мёртвые точки: рендер карточки в
   `heys_day_diary_section.js` вместе с гейтом `showDiaryWaterPanel`, проброс
   `waterCard` через `heys_day_tab_render_v1.js`, пункт настройки «Карточка
   воды» в `heys_app_shell_v1.js`, стили `.nutrition-v4-water*` в
   `732-ui-v4-nutrition.css`.
4. Чистка мёртвого после переписывания: `waterPresets`, `waterAddedAnim`,
   `showWaterDrop`, `waterMotivation`, `showWaterTooltip`, `handleWaterRing*` и
   их передача (`heys_day_water_card_v1.js`, `heys_day_tab_impl_v1.js`,
   `heys_day_water_state.js`, `heys_day_handlers_bundle_v1.js`).
5. Смоук `apps/web/__tests__/water-review-card-v4.test.js` (7 сценариев) +
   переписан кейс клика по чипу в `heys-day-water-persistence.test.js` на
   реальный рендер.
