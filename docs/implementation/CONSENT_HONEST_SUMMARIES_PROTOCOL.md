# Протокол реализации: честные пояснения к согласиям

## Цель

Пользователь до установки галочки видит не только юридическое название, но и
одну короткую фразу о содержании документа. Полный неизменяемый текст остаётся
доступен по ссылке и не подменяется пояснением.

## Решение

- Для регистрации общий экран показывает плашку «Коротко и честно» у каждого
  обязательного согласия, необязательных замеров и добавок, маркетинга и
  уведомлений.
- Уже вошедшие клиенты один раз видят отдельный экран «Замеры тела и добавки»
  без повторной оферты; те же пояснения, кнопка «Продолжить» без обязательных
  галочек.
- Для повторного согласия используются те же пояснения о содержании документов:
  пользователь решает, готов ли он принять актуальные условия, без разбора
  редакционных различий.
- Маркетинг явно остаётся добровольным и не влияет на доступ к HEYS.
- Обязательные согласия остаются на `ConsentScreen`; доподпись уже вошедших —
  `OptionalFeatureOfferScreen`.
