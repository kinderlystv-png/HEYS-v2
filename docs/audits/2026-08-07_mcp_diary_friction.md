## Вердикт

Цель: **быстро заносить данные клиента, умнее уточняя только где надо.**  
«Скинул только фото → сразу понял» = **зрение модели** + MCP, который
**показывает** картинку и **не прячет** path/id в structured. Серверного OCR в
HEYS нет и в этот ship не кладём (`маркетинг/38` — R&D отложен).
