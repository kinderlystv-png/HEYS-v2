# Точка отсчёта: отложенные MCP-инструменты в сессии Claude Code

Дата: 2026-08-25 · окружение: Claude Code, Windows, проект `HEYS-v2` Статус:
**baseline снят, изменение ещё не применено**

Это журнал одного изменения клиентской стороны коннектора: что было до, что
меняем, чем проверяем и как вернуть назад. Серверная часть (`heys-mcp`) не
затрагивается — правится только конфигурация клиента на этой машине.

## Симптом

`heys_update_day` был объявлен пользователю недоступным, и запись бытовой
активности переложена на ручной ввод в приложении — при полностью работающем
инструменте. Причина не в правах и не в сервере: схемы инструментов приходят в
сессию отложенными (видно имя, не видно параметров), а попытка подгрузить схему
делалась по короткому имени.

## Что измерено (3 вызова ToolSearch, 2026-08-25)

| Запрос                                      | Результат                             |
| ------------------------------------------- | ------------------------------------- |
| `select:mcp__<id сервера>__heys_update_day` | схема получена с первого раза         |
| `select:heys_update_day`                    | `No matching deferred tools found`    |
| `+update_day`                               | схема получена, ровно этот инструмент |

Вывод: индекс знает имена. `select:` требует точное полное имя с префиксом
сервера; `+<кусок имени>` работает без префикса. Версия «поиск идёт только по
описаниям полей» не подтвердилась.

## Состояние ДО изменения — это и есть точка возврата

| Что                                  | Значение на 2026-08-25                                                      |
| ------------------------------------ | --------------------------------------------------------------------------- |
| `~/.claude/settings.json`            | `{}` — пустой объект, ключа `env` нет                                       |
| `.claude/settings.json` (проект)     | только `hooks.PreToolUse` → `block-subagent-push.mjs`                       |
| `.mcp.json` в репозитории            | файла нет                                                                   |
| `~/.claude.json` → проект `HEYS-v2`  | `mcpServers: []`, `enabledMcpjsonServers: []`, `disabledMcpjsonServers: []` |
| `ENABLE_TOOL_SEARCH`                 | не задан нигде — действует поведение по умолчанию                           |
| Отложенных MCP-инструментов в сессии | ~126 (`heys_*` 49, `tasks_*` 35, chrome 22, сессии 8, прочее 12)            |

Серверы подключены не файлами репозитория, а коннекторами приложения — поэтому
`alwaysLoad: true` из документации к `.mcp.json` для них недоступен.

## Что меняем

В `~/.claude/settings.json`:

```json
{ "env": { "ENABLE_TOOL_SEARCH": "auto" } }
```

Значения по документации
([code.claude.com/docs/en/mcp](https://code.claude.com/docs/en/mcp.md), раздел
«Scale with MCP tool search»): не задано / `true` — откладывать всё; `false` —
грузить все схемы вперёд; `auto` — грузить вперёд, пока описания не займут 10%
окна контекста; `auto:N` — свой процент.

Почему `auto`, а не `false`: при ~126 инструментах их описания занимают десятки
тысяч токенов, и `false` отнимает эту часть окна в каждой сессии, в том числе
когда идёт обычная запись еды.

## Как откатить

Удалить ключ `env.ENABLE_TOOL_SEARCH` из `~/.claude/settings.json` и вернуть
файл к `{}`. Других следов изменение не оставляет: ни репозиторий, ни серверная
часть коннектора не затронуты. Откат вступает в силу в новой сессии.

## Чем проверяем эффект

1. Новая сессия в этом проекте.
2. Смотрим, попал ли `heys_update_day` в предзагруженные инструменты или остался
   в списке отложенных.
3. Считаем вызовы до первой записи в дневник — сравнение с happy path из
   [`2026-08-07_mcp_diary_friction.md`](2026-08-07_mcp_diary_friction.md).

## Чего не знаем

Порядок, в котором `auto` выбирает инструменты для предзагрузки, в документации
не описан. Попадут ли туда именно `heys_*`, а не chrome и задачник, заранее
неизвестно — проверяется только опытом. Если `heys_*` в 10% не попадают,
следующий шаг — не увеличивать процент вслепую, а отключить неиспользуемые
коннекторы в интерфейсе приложения.

## Правило, закрывающее сам симптом

Независимо от исхода эксперимента в `CLAUDE.md` есть раздел «Отложенные
MCP-инструменты (механика Claude Code)»: `select:` берёт только полное имя с
префиксом, короткое имя даёт «не найдено», и это не основание объявлять
инструмент отсутствующим или перекладывать запись на пользователя.
