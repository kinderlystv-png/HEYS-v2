# Бренд HEYS — исходники

Оригинальные файлы от дизайнера, добавлены 2026-07-31 из личной папки владельца.
Это **источник правды по логотипу и цветам**. Ассеты, которые реально грузит
приложение, лежат рядом с кодом (см. «Что использует продукт»); эту папку
приложение не импортирует.

## Что здесь

| Файл                                                             | Что это                                                                                             |
| ---------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- |
| [`logo/heys-logo-sheet.svg`](logo/heys-logo-sheet.svg)           | Все варианты логотипа в кривых. Из него нарезаются рабочие ассеты.                                  |
| [`logo/heys-logo-sheet.ai`](logo/heys-logo-sheet.ai)             | То же в Illustrator, кривые.                                                                        |
| [`logo/heys-logo-sheet-fonts.ai`](logo/heys-logo-sheet-fonts.ai) | Версия с живым текстом — для правок надписей, нужны шрифты.                                         |
| [`logo/heys-logo-report.txt`](logo/heys-logo-report.txt)         | Отчёт Illustrator: монтажная область 960×560, sRGB, список шрифтов.                                 |
| [`heys-design-sketch.pdf`](heys-design-sketch.pdf)               | Эскиз общего дизайна (16 МБ).                                                                       |
| `fonts/Agrandir-Regular.ttf`, `fonts/HeliosExtLightC.otf`        | Шрифты логотипа. **Проверить лицензию перед любым внешним использованием** — Agrandir коммерческий. |

## Варианты логотипа

В `heys-logo-sheet.svg` артборд декоративный: реальная графика лежит за его
пределами, поэтому файл открывается «пустым» в браузере. Смотреть в Illustrator
или нарезать по bounding box конкретной группы.

| Вариант                                                | Пропорции | Где применяется                            |
| ------------------------------------------------------ | --------- | ------------------------------------------ |
| Вертикальный, `lab` под `HEYS`                         | 192×162   | Шапка первого экрана лендинга (PNG-версия) |
| **Горизонтальный, `lab` после плюсов**                 | 284×105   | Залипающая мобильная шапка лендинга        |
| Со строкой «лаборатория нормализации пищевого баланса» | 188×103   | Пока не используется                       |

## Цвета

| Токен          | HEX       | Где                                       |
| -------------- | --------- | ----------------------------------------- |
| Синий          | `#1D70B7` | Основной: буквы логотипа, кнопки, акценты |
| Голубой        | `#52A0D8` | Плюсы в логотипе, декоративный узор       |
| Индиго         | `#434587` | Иконки, второй цвет исходного логотипа    |
| Светло-голубой | `#E2ECF2` | Подложки                                  |
| Зелёный        | `#DEEDDB` | Подложки в исходнике                      |
| Розовый        | `#F3D7D7` | Подложки в исходнике                      |

В исходном горизонтальном варианте буквы окрашены в индиго `#434587`. Для
лендинга он перекрашен в синий `#1D70B7`, чтобы совпадать с логотипом первого
экрана; плюсы оставлены голубыми `#52A0D8`.
