# Роли набора — замер оси, разметка к описи

Сгенерировано `scripts/ui-v4-measure-set-axis.mjs`. Правьте скрипт, не файл.

Файл **не заменяет** [опись](UI_V4_SAND_ROLES_INVENTORY.md) и ничего в ней не
решает: пометку `герой` ставит владелец. Замер отвечает на один вопрос — «что
случится с цветом, если заменить роль с именем набора на общую» — и показывает
ответ по каждому набору отдельно, чтобы решать не вслепую.

Мест с ролью набора: **500** вне комментариев.

Число мест дрейфует: модули правятся параллельно, и за один рабочий день оно
менялось трижды. Сверяйтесь с прогоном, а не с числом в тексте: SHA прогона в
отчёт намеренно не пишется — иначе файл пачкается при каждом запуске и мешает
параллельным сессиям.

Мест, где замена не меняла бы цвет, **нет ни одного** — почему, ниже.

## Что показал замер

**Ожидаемого короткого пути нет.** Замысел был такой: место, где роль не
различает наборы, можно заменить механически, без владельца. Замер этого не
подтверждает. Роль с именем набора действительно почти нигде не различает
песочный и синий — но общая роль, на которую её меняют, различает. Поэтому «не
различает наборы» означает не «замена безопасна», а ровно наоборот: замена и
есть то, что вернёт этому месту ось набора, и вместе с ней — другой цвет в
синих. Решение по каждому семейству остаётся за владельцем.

Зато замер делит места на три разных разговора вместо одного:

- 🎨 **425 мест** — пара по имени есть, замена меняет цвет. Здесь и нужен
  вердикт «герой или нет»: в таблице ролей видно, каким именно станет цвет в
  каждом наборе.
- ❓ **66 мест** — общей роли с таким именем нет вовсе (`--v4-act-deep`,
  `--v4-surface-soft` и подобные). Тут владельцу нужно сперва назвать пару, и
  только потом решать про героя. Имя не подсказывает её сам: честная пара к
  `--v4-sand-act-deep` — `--v4-act-text`, а не `--v4-act-deep`.
- 🚨 **9 мест** — роль не объявлена вовсе или объявлена не во всех наборах. Это
  не вопрос разметки: там цвет держит запасное значение у каждого места, и
  продукт уже сейчас не следует набору. Разбирать их стоит первыми и отдельно от
  разговора про героя.

это и есть предмет описи.
