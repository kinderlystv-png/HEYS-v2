**Дата:** 2026-09-03  
**Правки кода:** нет (только карта) · **Запретные зоны:**

**Правило лестницы (пересмотр 2026-09-03, вечер):** «мелкая подпись берёт 56 %
независимо от того, данные это или подпись» — для текста **строго мельче 12 px**

**Ограничение для emerald/green:** правило лестницы относится к **нейтральным**
чернилам (`--color-gray-*` → `--v4-ink-*`). Семейство `--color-emerald-*` —
**хроматический ok/act-акцент** (`--v4-ok-text`, `--v4-ok-fill`, `--v4-good`,
`--v4-act`), не ступень ink-ladder. Для emerald первичный фильтр — §3 «пара
шаг + вид свойства»; лестница проверяется только чтобы не спутать emerald с
серой подписью (в scope таких мест **нет** — см. §3.1).

Первичный разбор: Task 29 (утро). Пересмотр forks: Task 41 (вечер), тот же
фильтр, что `legacy-map-gray.md` (33774a280, 44b83c374, 007fb06c0) и
`legacy-map-blue.md` (d6473209f).
