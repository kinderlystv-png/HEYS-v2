## 11. Аудит соответствия контракта коду — сверка 2026-08-24

**Дата сверки: 2026-08-24.** Пакет `design_handoff_heys_v4/`, шестая сборка от
24.08; строки взяты из блоков `[data-contract]` (`data-v`), по одному проходу на
канвас. Это срез на дату, не живой статус: канвас правится отдельными коммитами,
поэтому после каждого пакета дизайна цифры устаревают. Машинный сторож
расхождений — `node scripts/ui-v4-check-contract-drift.mjs`.

**Что значат колонки:** `=` строка реализована в коде · `≠` код противоречит
контракту либо механики нет вовсе · `—` строка к коду не сводится (правила
самого канваса: демо-петли, номера видов, рамка 375 px, адресация кадров) · `?`
проверить не удалось. **Готовность** = `=` от строк, которые вообще сводятся к
коду, то есть от `всего − —`.
