## Как отвечать

По каждой находке — один из трёх ответов:

- **одобрить как правило** — кадр устарел, продукт верен, приводим кадр;
- **мы починим кодом** — кадр верен, правим продукт;
- **спорно** — нужен разбор, и тогда скажите, чем именно он спорен.

Колонка «наше предложение» — рекомендация до вашего ответа, не решение. Если
ответ меняет строку контракта, он приезжает поставкой пакета: переписанную
строку мы видим только оттуда, а не из письма.
