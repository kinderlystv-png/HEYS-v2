**Задача:** 27 · **Семейство:** `--color-blue-*` · **Дата:** 2026-09-03  
**Правки кода:** нет (только карта) · **Запретные зоны:**
`731-ui-v4-activity.css`, `300-modals-and-day.css`

**Правило лестницы (пересмотр 2026-09-03, вечер):** «мелкая подпись берёт 56 %
независимо от того, данные это или подпись» — для текста **строго мельче 12 px**

**Ограничение для blue:** правило лестницы относится к **нейтральным** чернилам
(`--color-gray-*` → `--v4-ink-*`). Семейство `--color-blue-*` — **хроматический
акцент** (act / act-text / wgt-link / water), не ступень ink-ladder. Для blue
первичный фильтр — §3 «пара шаг + вид свойства»; лестница чернил проверяется
только чтобы не спутать синий акцент с серой подписью (в scope таких мест нет).

## Проверка развилок фильтром §3 + лестница, 3 сентября

Замерено по коду в продуктовом scope (без `300-modals`), не оценено.

| Группа свойств                     | use-sites | Что говорит §3 / фильтр                                                                      |
| ---------------------------------- | --------: | -------------------------------------------------------------------------------------------- |
| `color:` (text) с `--color-blue-*` |        11 | **11 → act-text или wgt-link** по §3; лестница ink **не применяется** (хроматический акцент) |
| `background` / `fill`              |        12 | **12 → `--v4-act`** (F2, F7 сняты); из них **3** с парой `#2563eb` (F6)                      |
| `border` / `stroke` / `line`       |        18 | **17 → `--v4-act`** (фокус, актив); **1 → F3** (`rarity-rare` tier)                          |
| `box-shadow`                       |         2 | **2 → `--v4-act`**                                                                           |
| Alias-объявления                   |         5 | **D1/D2** — инфраструктура, не потребители                                                   |
| Тест                               |         1 | обновить при замене токена на роль                                                           |
| **Σ CSS-use**                      |    **43** | **42** без owner по цвету (минус F3); **+5** alias, **+1** тест                              |

**По кеглю (только `color:`, 11 мест):** явный `font-size` в том же правиле у
**5**; **2** мельче 12 px (`.sync-progress` 10 px, `.sparkline-brush-stats` 11
px) — оба **статус/оверлей**, целевая роль `--v4-act-text`, **не**
`--v4-ink-data` (лестница чернил к синему акценту не переносится). У **6** кегль
наследуется — при миграции смотреть родителя; семантика остаётся act/wgt, не
ink.

**Что фильтр закрыл сверх первичного списка:**

- **F4** была ложной: `blue-600` text везде = `--v4-wgt-link`, не спор с
  `act-text`.
- **F1** сократилась: конфликт «одна роль на токен» снят §3; остался **D1**
  (alias), по аналогии с gray F4 → дефект.
- **F7** не требует отдельной роли «progress» — это `--v4-act` fill.

**Владельцу остаётся:** **F3** (1 tier-border), **F5** (21 в `300` + ось ios),
вторая ступень **F6** (3 градиента). Инфраструктура **D1/D2** — чинить до или
параллельно массовой замене.
