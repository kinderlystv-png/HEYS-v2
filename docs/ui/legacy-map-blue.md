## Предлагаемые роли v4 (по паре шаг + вид)

Обоснование — **семантика ролей** из `002-ui-v4-palette-roles.css`, не близость
hex:

| Роль            | Смысл в 002                                         |
| --------------- | --------------------------------------------------- |
| `--v4-act`      | акцент действия (кнопка, заливка активного шага)    |
| `--v4-act-text` | текстовый тон действия / ссылки на акценте          |
| `--v4-water`    | вода (отдельная продуктовая ось, не «синий UI»)     |
| `--v4-wgt-link` | ссылка в виджете / переход («смотреть в Отчётах»)   |
| `--v4-edge`     | обводка контейнера (чернила 18 % — край, не акцент) |

### Таблица соответствий (in scope)

| `blue-ios` | **alias**           | `--v4-act` + `--v4-act-text` | iOS-синий — отдельная ось; в v4 уже мапится на act-text в dark. Литерал `#007aff` в `000` — кандидат на удаление alias     |

### Уже существующие alias (не трогать в этой задаче, только зафиксировать)

```css
/* 000-base-and-gamification.css:146 */
--color-blue-500: var(--v4-water, #3b82f6);

/* 200-dark-and-effects.css:47-51 */
--color-blue-500: var(--v4-act-text, #60a5fa);
--color-blue-600: var(--v4-act, #3b82f6);
--color-blue-ios: var(--v4-act-text, #60a5fa);
```

**Конфликт:** на светлом наборе legacy `blue-500` = **вода**, на тёмном =
**act-text**. Любая прямая замена `var(--color-blue-500)` → одна роль v4 без
учёта контекста сломает половину экранов.

## Краткий вывод

- Семейство **компактное**: 11 шагов, но **43** осмысленных CSS-use вне запретов
  (+ 5 alias + 1 тест).
- Доминирует **`--color-blue-500`** (38 in scope): смешивает
  text/fill/line/shadow — главный кандидат на поштучную миграцию, не массовую
  замену.
- **`--color-blue-ios`** живёт почти целиком в запретной `300` — карта фиксирует
  долг, решение откладывается.
- Центральный риск — **F1**: alias уже разводит water и act-text по теме; агент
  не должен «угадывать» одну роль на всё семейство.
