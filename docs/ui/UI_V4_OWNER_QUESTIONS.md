# Решения владельца v4

Страница держит **открытые** вопросы к владельцу. Сейчас открытых нет: три
последних закрыты 10 сентября 2026 — разбор в
[`UI_V4_FINDINGS_HISTORY.md#owner-decisions-three-2026-09-10`](UI_V4_FINDINGS_HISTORY.md#owner-decisions-three-2026-09-10).

Формат для новых: **зачем спрашиваем** → **что видит человек сейчас** →
**варианты с ценой** → **рекомендация**. Вопрос должен решаться без чтения кода:
если для ответа надо открыть исходник, вопрос сформулирован плохо.

---

## Закрыто 10 сентября

| Вопрос                                                      | Решение                                                                                                    |
| ----------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `norm-correction` · NC5 · 07 — текст про обхваты недостижим | Писать **третью ветку прозы** под случай «есть только талия». Сервер на бедро и бицепс сейчас не расширяем |
| `strength-builder` · Г3 — «Перенести» и «Пропустить»        | Разведены **окончательно**; кадр переснимается, продукт не откатывается                                    |
| `nutrition-tab` / `tips` — «Совет с заменой»                | Механики **не будет** (решение № 35). Вернуться, когда появятся живые люди                                 |

**Что изменило ответ на первый вопрос.** Живых клиентов ещё нет — система
строится, в проде владелец и второй куратор. Поэтому «сколько людей задето» тут
не критерий, и предложенная проверка по замерам обхватов снята как
бессмысленная. Решило другое: случай «человек мерит только талию» останется
навсегда, даже если сервер начнёт отдавать все обхваты, — значит честный текст
под него нужен в любом раскладе.

**Что осталось после решений.** Первое требует прозы от дизайнера: до неё
вердикт строки 07 остаётся `?`, зона `norm-correction` не закрывается. Второе и
третье закрыты полностью.
