# Лист приёмки — `questionnaire.v4.dc.html`

Переснят 3 сентября 2026 (двадцать шестая сборка). Всего строк — 325, разделов — 12. Непокрытых текстовых узлов нет. Кадры зоны — 375 px (правило сверки проекта).

**Три последних раздела — слепок канваса, выведенный из разметки скриптом `contract-snapshot.js`.** Расходится строка с кадром — верен кадр, слепок переснимается командой «пересними слепки»; руками он не правится.

Как заполнять: «Ожидание» — значение из контракта дословно. «Вердикт»: `=` совпало · `≠` расходится · `—` не в этот релиз · `?` не измеряется.
