# Лист приёмки — `login.v4.dc.html`

Переснят 3 сентября 2026 (двадцать шестая сборка). Всего строк — 788, разделов — 12. Непокрытых текстовых узлов нет. Кадры зоны — 375 px (правило сверки проекта).

**Три последних раздела — слепок канваса, выведенный из разметки скриптом `contract-snapshot.js`.** Расходится строка с кадром — верен кадр, слепок переснимается командой «пересними слепки»; руками он не правится.

Как заполнять: «Ожидание» — значение из контракта дословно. «Вердикт»: `=` совпало · `≠` расходится · `—` не в этот релиз · `?` не измеряется.

Блокировка входа — состояние экрана: карточка на заливке с заголовком «Слишком много попыток входа» и строкой «Напишите куратору — он снимет блокировку». Разный вес разным отказам: в блокировке человек не может ничего, и единственный выход к живому куратору не может быть набран тем же кеглем, что «код не подошёл». Решение 31 августа (ответ на срез вопросов кодера): Две строки про подпись стоят при СОЗДАНИИ кода, а не позже: «Код доступа заменяет собственноручную подпись» и «Не сообщайте код никому, включая куратора». Человек придумывает код, которым будет подписывать документы, — объяснять это после подписания или только после сброса поздно. Было до этого решения: экран не объясняет себя: заголовок называет действие («Вход»), поля подписаны существительными («Телефон», «Код от куратора»), кнопки — глаголами в первом лице продукта («Войти» здесь нет вовсе — вход происходит по четвёртой цифре). Ошибки называют причину и следующий шаг, а не факт отказа: «Код не подошёл. Осталось две попытки», а не «Ошибка входа». Слова «PIN», «логин», «аккаунт» на экране не используются |  |  |
| возврат на экран и прокрутка | экран входа не прокручивается вовсе: содержимое умещается в высоту при открытой клавиатуре — при фокусе панель палитр сворачивается, освобождая место. Возврат из фона показывает тот же шаг с сохранёнными цифрами кода; после блокировки вход открывается заново пустым |  |  |
