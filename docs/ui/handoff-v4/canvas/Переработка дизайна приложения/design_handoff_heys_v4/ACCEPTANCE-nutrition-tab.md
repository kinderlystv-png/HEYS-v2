## Как заполнять

- Вердикт: **=** совпало · **≠** расходится (написать факт) · **—** не
  реализовано · **?** не проверить без решения дизайна.
- Значение брать из `data-v`, не из прозы «Решений» и не из длительностей CSS
  демо-петель.
- Геометрию сверять на 375 px и только по кадрам `data-demo="stop"`; кадры
  `protocol` для сверки не годятся. Экран по умолчанию собран одной полосой —
  блоки адресуются метками `Питание · блок · …`.
- Каждый факт — с путём и строкой (`file.js:1234`). Где нашлось два разных
  значения одного и того же — писать оба места.
- Строка с вердиктом ≠ закрывается либо правкой кода, либо правкой контракта —
  но не молча.

## После заполнения

- Строки **≠** — свести в одно место и решить каждую: правка кода или правка
  контракта.
- Строки **—** — оценить часами; действия приёма, свайп, тост отмены, советы
  приёма и лист выбора цели почти наверняка окажутся здесь.
- Строки **?** — вернуть дизайну.
