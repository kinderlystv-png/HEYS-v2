# Приёмка — вкладка «Питание»

Лист приёмки собран из контракта канваса `nutrition-tab.v4.dc.html` — по строке
на каждый `data-v`. Значения здесь копия контракта: при расхождении верен
канвас, и правится он.

Строк: **214**.

## Что это и чьё

| Ключ        | Что проверить                                                                                                                                                                                                                                                                        |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `фича`      | вкладка «Питание»: остаток дня, окно приёмов, дневник приёмов, разбор дня, настраиваемые блоки                                                                                                                                                                                       |
| `границы`   | канвас рисует содержимое вкладки от шапки до ряда чипов; нижняя навигация, плавающие кнопки и шторки добавления — свои канвасы                                                                                                                                                       |
| `источник`  | главный для вкладки, дневника приёмов, разбора дня и ряда чипов настройки                                                                                                                                                                                                            |
| `демо`      | data-demo='stop' — статичные кадры, по ним сверять геометрию на 375 px · data-demo='protocol' — отвергнутые или переехавшие кадры (планнер уехал в tab-insights), не реализовывать                                                                                                   |
| `адресация` | кадр = data-screen-label, метки уникальны в файле. Полоса «Вкладка целиком» несёт по одному кадру на блок в каноничном порядке; другие состояния тех же блоков стоят колонкой справа («Вариации · Итоги дня», «Вариации · Вода», «Вариации · Добавки») и в порядок вкладки не входят |

| `убавление`                          | чип −200 живёт только в полном виде; при включённой кнопке воды убавляют на ней же, второго места для этого в карточке нет. Проверяется тем же гейтом подписки, что и добавление                                                                                                                                                                                                                                                 |
| `только чтение · вода`               | в режиме только чтения и без подписки карточка показывается целиком, гаснут до 40 % лишь чипы объёмов и чип убавления; кольцо, график и попап нормы работают. Тревожное состояние показывается и здесь — оно про факт, а не про возможность записать                                                                                                                                                                             |
| `тревога в полном виде`              | выглядит ровно так же: кольцо в тревожном тоне, градиент на последнем участке линии, остальное без изменений. Отдельного кадра нет намеренно — вид отличается только диаметром кольца и наличием чипов                                                                                                                                                                                                                           |
