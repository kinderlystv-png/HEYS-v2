# Лист приёмки — `water-add.v4.dc.html`

Переснят 5 сентября 2026 (снятое адресовано парой data-removed / data-was). Всего строк — 231, разделов — 4. Непокрытых текстовых узлов нет. Кадры зоны — плитки и карточки вариантов в натуральном размере, экрана целиком в зоне нет.

**Контракт зоны лежит шестью блоками:** основной плюс «Параметры», «Края и поведение», «Звук капли», «Параметры звука», «Как это работает» — прежде пять из них стояли вне обёртки `[data-contract]`, поэтому счётчик, твик и лист приёмки видели только 60 строк из тогдашних 134.

**Три последних раздела основного блока — слепок канваса**, выведенный скриптом `contract-snapshot.js`. Расходится строка с кадром — верен кадр, слепок переснимается командой «пересними слепки».

Как заполнять: «Ожидание» — значение из контракта дословно. «Вердикт»: `=` совпало · `≠` расходится · `—` не в этот релиз · `?` не измеряется.
