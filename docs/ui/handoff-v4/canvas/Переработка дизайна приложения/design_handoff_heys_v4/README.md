# HEYS v4 — пакет для разработки

Собран 18 августа 2026. Всё, что нужно, лежит внутри этой папки: ничего
доустанавливать и скачивать не требуется.

## Начните с `INDEX.md`

В нём карта «фича → канвас → метка экрана → файлы кода» и правила чтения
канвасов. Файлы канвасов названы слагами; человеческое название написано в шапке
каждого.

## Что изменилось в этой сборке

- Лист «все вкладки одним файлом» разобран: теперь канвас на вкладку —
  `tab-food`, `tab-activity`, `tab-reports` (вместе с разбором Score),
  `tab-insights`.
- Всё про виджеты Главной собрано в `home-widgets.v4.dc.html`: дефолт в четырёх
  палитрах, режим расстановки, четыре размера, правила плитки и кольца БЖУ
  (подписи над кольцами, «факт / норма» под ними, красным только отклонение — у
  белка обратное).
- Строка даты обновлена по коду: при прокрутке капсула со стрелками висит
  сверху, на прошлом дне над ней остаётся плашка режима. Прежняя «сжатая шапка»
  из канваса куратора снята.
- Дубли правил сняты: правила экрана входа живут только в `login`, скелетоны из
  продукта убраны (причина — в `spinners`), снятые листы уехали в `history/`.

## Как открывать

Распакуйте папку целиком и открывайте любой `*.dc.html` двойным щелчком в
браузере. Файлы работают только рядом с `support.js` и `v4-canvas.css`, которые
лежат тут же, — не переносите отдельный html в другое место.

Если нужно отправить один экран в мессенджер, берите файл из `standalone/`: там
четыре канваса нового слоя, склеенные в самодостаточные html (открываются откуда
угодно, но код внутри не читается — только смотреть).

## Что это за файлы

Канвас — это не картинка, а страница ревью: слева направо идут экраны телефона,
справа от каждого ряда стоит колонка **«Решения»** с обоснованием каждого
правила. Колонка — часть спецификации: если экран и текст расходятся, прав
текст.

Четыре канваса нового слоя (Регистрация, Утренний чек-ин, Правки куратора,
Настройки и системное) собраны иначе, чем остальные: экраны лежат в одном
экземпляре, а под каждым светлым рядом сразу идут три остальные палитры —
тёмная, синяя и сине-тёмная. Переключателей нет, всё видно сразу. Палитры
описаны переменными в `v4-canvas.css` — цвета брать оттуда, не из инлайновых
стилей.

## `history/` — контекст, не спецификация

Ранние ветки и снятые листы: `Актив - этап 4`, `Визуал v4`,
`Отчёты и Инсайты v4`, `Скелетон v4`, `HEYS - редизайн вкладок`, `HEYS Мягкий` и
тёмная версия, `HEYS v2 - все вкладки`, сравнения v2↔v3 и v2↔v4, `Актив v2`,
`Актив - было и стало`, `Визуал v3`, `Отчёты v2`, `Питание v2`. Правила, которые
выжили, перенесены в актуальные канвасы. Реализовывать по `history/` нельзя —
только смотреть, почему решения такие.

## `standalone/`

`registration.v4.html`, `checkin-morning.v4.html`, `curator-edits.v4.html`,
`settings-system.v4.html` — по одному самодостаточному html. Удобно переслать,
неудобно читать.

## Что не входит

Кода приложения здесь нет: пакет описывает интерфейс и правила. Ассеты — только
логотип в `assets/`; фотографий и иллюстраций в макетах нет намеренно, места под
них помечены на канвасах.
