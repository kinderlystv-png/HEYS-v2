# Лист приёмки — Поправка на факт (`norm-correction.v4.dc.html`)

Собран 31 августа 2026 из контракта канваса: одна строка проверки на каждый
`data-v`. Всего строк — 46, разделов — 10. **В прод идут все 19 кадров:** на Pro
поправку применяет куратор, на Self — сам клиент; рост нормы применяется
системой с уведомлением и кнопкой отмены, снижение требует явного согласия.
Открытыми остаются две строки в разделе «Открыто до передачи».

Как заполнять: «Ожидание» — значение из контракта дословно, его не переписывать.
«Факт в коде» — что реально в реализации. «Вердикт»: `=` совпало · `≠`
расходится (тогда правится код, контракт верен) · `—` не реализуется в этом
релизе · `?` не измеряется. Все кадры канваса — `data-demo="stop"`, статичные;
экраны адресуются атрибутом `data-screen-label`, зеркала палитр несут суффикс.
