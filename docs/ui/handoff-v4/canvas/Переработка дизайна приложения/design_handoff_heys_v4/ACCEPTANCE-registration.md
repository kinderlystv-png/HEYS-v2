# Лист приёмки — `registration.v4.dc.html`

Переснят 3 сентября 2026. Всего строк — 555, разделов — 9. Непокрытых текстовых узлов нет.

**Три последних раздела — слепок канваса, выведенный из разметки скриптом `contract-snapshot.js`, а не написанный по памяти.** «Разбор кадров» — строка на каждый нарисованный элемент (ключ = метка кадра и номер сверху вниз); «Разбор графики» — поля рисунков, точки ломаных, пунктиры, маркеры; «Текст кадров дословно» — вся копия сверху вниз через знак ›. Расходится строка с кадром — верен кадр, слепок переснимается командой «пересними слепки». Руками слепок не правится.

Как заполнять: «Ожидание» — значение из контракта дословно. «Вердикт»: `=` совпало · `≠` расходится (правится код, контракт верен) · `—` не в этот релиз · `?` не измеряется.
