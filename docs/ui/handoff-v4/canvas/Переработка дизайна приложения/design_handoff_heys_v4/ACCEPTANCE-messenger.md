# Лист приёмки — `messenger.v4.dc.html`

Переснят 7 сентября 2026 (чипы фильтра поиска 44 px). Всего строк — 277, разделов — 9. Непокрытых текстовых узлов нет. **Три последних раздела — слепок канваса, выведенный из разметки скриптом `contract-snapshot.js`.** Расходится строка с кадром — верен кадр, слепок переснимается командой «пересними слепки»; руками он не правится.
