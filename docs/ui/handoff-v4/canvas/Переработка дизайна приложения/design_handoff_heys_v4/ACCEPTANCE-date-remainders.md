# Приёмка — дата, календарь, поверхности советов

Лист приёмки собран из контракта канваса `date-remainders.v4.dc.html` — по
строке на каждый `data-v`. Значения здесь копия контракта: при расхождении верен
канвас, и правится он.

Строк: **64**.

## Что это и чьё

| Ключ                   | Что проверить                                                                                                                                                                                                                                                                                |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `фича`                 | строка даты в шапке трёх дневных вкладок — Главная, Питание, Актив; шторка календаря, ночь до 03:00, остатки дня. В Отчётах и Инсайтах капсулы дня нет — там период вместо дня                                                                                                               |
| `границы`              | канвас рисует капсулу, стрелки, сетку календаря и содержимое шторок; шапка вкладки, её паддинг и скролл-контейнер — продукта                                                                                                                                                                 |
| `источник`             | главный для капсулы даты и календаря на всех вкладках                                                                                                                                                                                                                                        |
| `область действия`     | капсула живёт в шапке трёх дневных вкладок — Главная, Питание, Актив: они показывают один день. Отчёты и Инсайты работают периодом (неделя, месяц), капсулы дня там нет и она не выключается, а не существует. Одна реализация на три вкладки, не пять                                       |
| `адресация`            | кадр = data-screen-label                                                                                                                                                                                                                                                                     |
| `палитры`              | все роли из v4-canvas.css; кадры нарисованы в четырёх палитрах, тон метки календаря выверен в каждой отдельно — строка «тон метки»                                                                                                                                                           |
| `доступность`          | капсула — кнопка с подписью полной даты («воскресенье, 16 августа»), а не «Сегодня»: слово остаётся на экране, но озвучивается дата. Стрелки — «Предыдущий день» и «Следующий день», у погашенной aria-disabled. Клетка календаря озвучивает дату и наличие записи словом, точка декоративна |
| `уменьшенное движение` | прилипание капсулы при прокрутке и раскрытие шторки календаря становятся мгновенными; тень липкого слоя появляется без перехода                                                                                                                                                              |
