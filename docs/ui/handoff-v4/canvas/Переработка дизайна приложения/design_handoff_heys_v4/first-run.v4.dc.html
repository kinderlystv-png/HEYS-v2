Первый вход обзор приложения · четыре шага · вход с компьютера · v4

Что человек видит сразу после регистрации и до первой записи. Один обзор из четырёх шагов по настоящему экрану, без выдуманных чисел и без второго приветствия; отдельный экран для тех, кто открыл HEYS с компьютера. В коде на это место приходятся три разных тура (общий на восемь шагов, мини-тур Инсайтов и тур виджетов из демо-части и части правки) — здесь остаётся один, остальные названы снятыми.

QR рисует приложение, а не чужой сервиспроза канваса живёт дольше решения: ложный факт в ней потом всплывёт как аргумент — поэтому неверная причина не стёрта, а названа неверной. Правка 5 сентября по замеру владельца: в кадре стояли 21 модуль и код 126 px — самосогласованно, но для адреса БЕЗ схемы, которого код не кодирует. Верен код, поправлен кадр
тихая зона · дефект кода«чаще всего просканируется» — не то свойство, за которым возвращают сканер вместо кнопки «Скопировать».
