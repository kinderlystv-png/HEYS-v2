# Лист приёмки — продукт в базе (`product-card.v4.dc.html`)

Собран 28 августа 2026 из контракта канваса: одна строка проверки на каждый
`data-v`. Всего строк — 29, разделов — 5. Вторая половина разделённой зоны еды;
приём и список продуктов — в `ACCEPTANCE-food-meal.md`.

Как заполнять: «Ожидание» — значение из контракта дословно, его не переписывать.
«Факт в коде» — что реально в реализации. «Вердикт»: `=` совпало · `≠`
расходится (тогда правится код, контракт верен) · `—` не реализуется в этом
релизе · `?` не измеряется. Геометрию сверять на 375 px и только по кадрам
`data-demo="stop"`; кадры `data-demo="loop"` — демо-петли канваса, их тайминги
не спецификация; `data-demo="protocol"` — отвергнутая ветка, не реализовывать.

Экраны адресуются атрибутом `data-screen-label` — метка ищется целиком,
формулировки не угадывать.
