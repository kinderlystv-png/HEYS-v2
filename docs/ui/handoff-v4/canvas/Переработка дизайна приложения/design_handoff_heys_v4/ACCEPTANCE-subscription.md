# Лист приёмки — `subscription.v4.dc.html`

Переснят 6 сентября 2026 (все четыре написания палитр переведены на ступени). Всего строк — 257, разделов — 12. Непокрытых текстовых узлов нет. **Три последних раздела — слепок канваса, выведенный из разметки скриптом `contract-snapshot.js`.** Расходится строка с кадром — верен кадр, слепок переснимается командой «пересними слепки»; руками он не правится.

Канвас рисует две фазы: Фаза 1 (`paymentsEnabled=false`) идёт в прод сейчас, Фаза 2 (тарифы и ЮKassa) реализуется за флагом и включается без правок дизайна.

Как заполнять: «Ожидание» — значение из контракта дословно. «Вердикт»: `=` совпало · `≠` расходится · `—` не в этот релиз · `?` не измеряется.

Pro Спорт не оплачивается картой: его кнопка — «Написать в поддержку», подпись «подключение после согласования». Цены на кадрах — иллюстрация, источник — конфиг |  |  |
| три сигнала «только чтение» | остаются все три: липкий баннер сверху на всех вкладках, плашка на вкладке «Питание» (nutrition-tab), тост при тапе по заблокированному действию. Каждый ведёт в один слой — модалку подписки (по фазе). Баннер одного состояния: активный пробный период шапку не занимает, предупреждения «осталось N дней» нет — срок виден в настройках |  |  |
| контакт поддержки — список | РЕШЕНИЕ ВЛАДЕЛЬЦА 5 сентября: фаза 1 показывает ОДИН ряд — общий контакт поддержки, «Поддержка HEYS · @heys_support · отвечаем в рабочее время», внешняя ссылка t.me. Не список и не персональные контакты куратора: в схеме curators контактных полей нет вовсе, а персональные контакты — это колонка в базе, экран профиля куратора и модерация того, что он публикует, и в релиз это не идёт. Перехода во встроенный мессенджер здесь нет: подписка оформляется там, где принимают оплату |  |  |
| шаги оплаты — как в коде | тариф → «проверьте заказ» (название, цена, срок, согласие с офертой, «Оплатить N ₽») → страница ЮKassa (внешняя) → возврат в приложение → «оплата прошла». Промежуточный экран не пропускается: на нём живёт согласие с офертой, которое код обязан записать до платежа (payment_oferta, ст. 438 ГК) |  |  |
| очередь на пробный период | рисуется внутри модалки тарифов под разделителем «или»: четыре состояния блока — места есть / мест нет / заявка подана / место освободилось (оффер с таймером). Окно оффера — 120 минут (offer_window_minutes), таймер показывает ч:мм:сс |  |  |
| слова на экране | «пробный период» в предложениях, «Триал» — только как название статуса в настройках и в кабинете куратора; без «ты», без восклицаний, без эмодзи. Заголовки называют состояние («Пробный период закончился»), а не требование («Нужна подписка»). Кнопки называют действие с объектом: «Написать в поддержку», «Оформить Pro», «Оплатить 7 990 ₽», «Начать пробный период», «Встать в очередь» |  |  |
| иконки | Lucide, обводка 2,75: замок в шапке модалок «только чтение», галочка в списке включённого, стрелка-шеврон в рядах, крестик закрытия. Эмодзи из кода (🔒 🎉 👨‍⚕️ ⏳ 🟢 🔴 💳 ✅) снимаются все |  |  |
