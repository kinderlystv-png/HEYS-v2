# Лист приёмки — `first-run.v4.dc.html`

Переснят 6 сентября 2026 (все четыре написания палитр переведены на ступени). Всего строк — 132, разделов — 9. Непокрытых текстовых узлов нет. **Три последних раздела — слепок канваса, выведенный из разметки скриптом `contract-snapshot.js`.** Расходится строка с кадром — верен кадр, слепок переснимается командой «пересними слепки»; руками он не правится.

Три тура кода (общий, мини-тур Инсайтов, тур виджетов) сводятся в один обзор из четырёх шагов. Экран входа с компьютера даёт **два пути** на телефон — QR и адрес `app.heyslab.ru` с кнопкой «Скопировать». QR кодирует `https://app.heyslab.ru` со схемой, отсюда 25 модулей: код 150 px при клетке 6 px плюс тихая зона 4 модуля — квадрат 198 px. Рисует его само приложение локально, без сети: состояний «загружается» и «ошибка сети» у него нет. **Полоса 5 — дефект кода:** `createDataURL(4, 0)` оставляет тихую зону нулевой, ожидание кадра `createDataURL(4, 4)`.

Как заполнять: «Ожидание» — значение из контракта дословно. «Вердикт»: `=` совпало · `≠` расходится · `—` не в этот релиз · `?` не измеряется.


Требование тихой зоны QR переписано свойством, а не именем вызова.

| вход с компьютера — не заглушка, а короткий путь | человек, открывший HEYS на компьютере, видит один экран: почему только телефон, ДВА пути попасть на телефон — QR-код и короткий адрес с кнопкой «Скопировать», — как поставить на домашний экран, и тихий выход. Порог — ширина окна больше 768 px; куратора экран не трогает (кабинет — рабочее место за компьютером), вкладка «Задачи» его пропускает, обходной флаг desktopAllowed остаётся. Порядок сверху вниз: что происходит и почему → способ попасть на телефон → «на домашний экран» → «Выйти из аккаунта». QR и адрес стоят ВМЕСТЕ, а не вместо друг друга: камера и руки — два пути к одному адресу |  |  |
| QR рисует приложение, а не чужой сервис | код собирается на клиенте, локально, без сети. Поэтому у него НЕТ состояния «загружается» и НЕТ состояния «не удалось загрузить» — рисовать эти состояния не нужно, их больше не существует; в кадре обычный квадрат заданного размера. ЧТО КОДИРУЕТСЯ: https://app.heyslab.ru — СО СХЕМОЙ, а не голый домен: голый домен камера распознаёт как ссылку не всегда, а экран существует ради гарантированного попадания на сайт. Отсюда размер: со схемой это 25 модулей при любом уровне коррекции, клетка 6 px даёт код 150 px, тихая зона по стандарту 4 модуля с каждой стороны — квадрат 198 px. Прежняя картинка приходила запросом на api.qrserver.com — и это снято. Причина точная (первая редакция строки называла неверную — будто уходил адрес страницы с параметрами сессии): в запросе передавался window.location.origin (heys_app_gates_v1.js:121), только домен, без пути, запроса и хвоста, никакие данные сессии не утекали. Утекало другое и на каждом заходе с компьютера: чужому сервису доставались IP посетителя и сам факт пользования HEYS. Плюс дырка в CSP ради одной картинки — img-src … https://api.qrserver.com в index.html:22 держится только ради неё и уходит вместе с ней |  |  |
| тихая зона · дефект кода | ДЕФЕКТ В КОДЕ, полоса 5 (найден владельцем 5 сентября). Требование — СВОЙСТВО КАРТИНКИ, а не имя вызова: вокруг кода обязана быть тихая зона НЕ МЕНЬШЕ ЧЕТЫРЁХ МОДУЛЕЙ; минимум приёмки — два модуля; ноль не проходит. При клетке 6 px это 24 px с каждой стороны и квадрат 198 px (четыре модуля) либо 12 px и 174 px (два, минимум). Чем это нарисовано — dataURL, inline-SVG или canvas — контракта не касается: сейчас в коде createDataURL(4, 0) и второй аргумент, поле вокруг кода, стоит нулём, но покраснеть строка должна на нулевой зоне, а не на смене способа отрисовки |  |  |
| слова на экране | без «ты», без восклицаний, без эмодзи. Заголовки шагов называют, что человек здесь делает («Записать еду и воду»), а не хвалят функцию («Уникальная фишка HEYS»). В тексте шага одно предложение, максимум два |  |  |
| иконки | Lucide, обводка 2,75: layout-grid, plus, compass, bar-chart-2 в кадрах навигации; copy на кнопке адреса; smartphone на экране входа с компьютера (QR иконкой не считается — это код, а не знак); log-out у тихого выхода. Эмодзи кода (📊 🎛️ 🍴 🔮 🔥 💡 🎉 🍽️ 🥛 ⚖️ 💧 📅 ⚠️ 🤖 ✨ 🎯) сняты все |  |  |
