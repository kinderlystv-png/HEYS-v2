# Приёмочный лист — Особый период (цикл)

Собран 26 августа 2026 из контракта `cycle.v4.dc.html`. Лист производный: при
расхождении верен контракт.

Строк в контракте: **78**.

**Контракт намеренно расходится с кодом.** Множители пересчитаны по физиологии
26 августа; `heys_cycle_v1.js` держит прежние. По строкам «множитель калорий»,
«множитель воды», «волна», «фазы и подписи» и «тренд веса» первое расхождение
ожидаемо — правится код. Геометрию сверять на 375 px.

**У канваса есть сверка.** В шапке стоит строка `audit()`: она обходит кадры и
ищет поверхность без строки «вид», кнопку мимо общего ряда, число в прозе вне
контракта и живой замер, разошедшийся со своей строкой. На момент сборки строка
пустая — «сверка чиста».
