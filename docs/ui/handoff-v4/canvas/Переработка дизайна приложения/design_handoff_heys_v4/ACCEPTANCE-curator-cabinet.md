## Открытие карточки и срок решения

| Ключ                            | Ожидание (контракт)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Факт в коде | Вердикт |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- | ------- |
| лист поверх панели              | тап по строке открывает лист снизу, панель под ним остаётся на той же позиции прокрутки: куратор смотрит клиентов подряд, и уход на отдельный экран сбивает место в списке. Разворот строки отвергнут — в карточке шесть чисел и две кнопки                                                                                                                                                                                                                                                                                                                             |             |         |
| состав листа                    | шапка с инициалами, именем, окном («окно 21 день · 10–30 авг») и тарифом; три строки чисел — формула, факт, норма дня станет; четыре действия в этом порядке: «Применить с завтра» пилюлей 48 на --acs, ниже ряд из двух — «Отложить» и «Заморозить» на --c2, последней «Открыть дневник» на --c2 во всю ширину. Отложить и заморозить обязательны: без них строка уходит из «ждут решения» только применением. Полная карточка — качество данных, «где может сидеть расхождение», история решений — в norm-correction, лист показывает её же и ничего не пересчитывает |             |         |
| что меряет пилюля               | число справа всегда значит одно — сколько дней длится состояние, и никогда не важность. У молчания это дни без записей, у расхождения — длина окна расчёта, у «ждут решения» — дни с понедельника, когда предложение посчиталось.
