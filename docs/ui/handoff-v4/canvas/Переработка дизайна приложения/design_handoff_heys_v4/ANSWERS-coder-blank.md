# Ответы кодера — бланк

Заполняется поверх этого файла и возвращается файлом, не сообщением в чате: каждый ответ станет строкой контракта, а строка контракта не собирается из переписки.

Три поля на пункт раздела А. «Не знаю» — законный ответ, «нет, никогда не делали» — тоже. Правдоподобная догадка — нет: она попадёт в контракт числом и будет жить там как факт.

## Что происходит после

Каждый ответ становится строкой `data-v` на своём канвасе. Пункт уходит из раздела «Открыто до передачи» только вместе с появлением такой строки: счётчик открытых обязан упасть ровно на число закрытых. Это проверяется сверкой, а не объявляется словом «учтено».
