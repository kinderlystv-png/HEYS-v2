## Как заполнять

- Вердикт: **=** совпало · **≠** расходится (написать факт) · **—** не
  реализовано · **?** не проверить без решения дизайна.
- Значение брать из `data-v`, не из прозы и не из демо-петель. Геометрию сверять
  на 375 px по кадрам `data-demo="stop"`.
- Изменения 23 августа: разделы «Бюджет экрана», «Быстрые действия», «Кнопка
  настройки экрана»; «Плитка добавления» снята — одна строка «снятая плитка
  добавления», кадры помечены `data-demo="protocol"`. Дефолт пересобран под 32
  клетки: «Вес» 2×1, строка «Изменить экран» и пунктирная плитка убраны.
- Пилюля «＋ Записать» снята: FAB всегда круг 52×52 с «+». Строка «снятая
  пилюля» ожидает вердикт **—**.
- Заливка, знак и тени FAB названы строкой «вид кнопки».
- Ключи уникальны (проверено при сборке).
- Новые виджеты (клетчатка, белок, окно до сна, качество еды, ритм приёмов,
  готовность ко сну — виды 37–51) кодом ещё не реализованы: их строки ожидают
  **—**.
- Каждый факт — с путём и строкой (`file.js:1234`).
