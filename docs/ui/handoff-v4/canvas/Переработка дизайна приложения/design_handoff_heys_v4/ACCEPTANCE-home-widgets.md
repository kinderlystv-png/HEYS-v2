# Приёмка — Главная: виджеты, быстрые действия, разборы

Лист приёмки собран из контракта канваса `home-widgets.v4.dc.html` — по строке
на каждый `data-v`. Значения здесь копия контракта: при расхождении верен
канвас, и правится он.

Строк: **280**.

## Пороги окраски

| Ключ                         | Что проверить                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `вода`                       | та же шкала, что у «Итогов дня» на вкладке «Питание»: ожидаемое = дневная норма × k, где k = (сейчас − подъём) / (конец окна − подъём), зажат в 0…1; отклонение считается разностью (ожидаемое − факт) / дневная норма. Вниз: до 8 % — шалфей, 8–25 % — предупреждение, больше 25 % — красный. Вверх от дневной нормы: больше 110 % — предупреждение, больше 130 % — красный. Конец окна у воды — отбой минус 1 ч, у еды отбой минус 3 ч. Первый час после подъёма не красим                                                                                                    |
| `одна шкала на весь продукт` | форма правила одна для всех поверхностей: окно из чек-ина, ожидаемое = норма × k, сравнение разностью, зоны 8 / 25 % вниз и 110 / 130 % вверх. Различается только конец окна: у еды отбой минус 3 ч (после последнего приёма нужен запас до сна), у воды отбой минус 1 ч (пить перед самым сном — будить себя ночью). Подъём и отбой — из утреннего чек-ина; их нет — окно 08:00–21:00. Главная своих порогов не заводит: дневная норма воды приходит из water-add.v4.dc.html, нормы нутриентов из профиля, а зоны и запасы — константы дизайна, названные на вкладке «Питание» |
| `сон`                        | не ниже нормы профиля − 30 мин — шалфей · ниже — красный · пересып не красим                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `вес`                        | мёртвая зона ±0,2 кг за окно · направление из окна спарклайна (растущее: с 7 дней, затем 2, 3, 4 недели, дальше месяц), не из разницы с прошлым взвешиванием                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `БЖУ`                        | жиры и углеводы краснеют на переборе, белок — на недоборе; порог общий, в коде один компаратор с флагом направления                                                                                                                                                                                                                                                                                                                                                                                                                                                             |

## Данные и пустые состояния

| Ключ                               | Что проверить                                                                                                                                                                                                                                                                       |
| ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `нет данных за день`               | на месте числа прочерк, подпись остаётся; полосы, кольца и спарклайны не рисуются, ноль не подставляется.
