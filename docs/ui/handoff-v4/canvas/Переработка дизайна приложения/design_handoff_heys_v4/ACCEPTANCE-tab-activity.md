## Тренировки, быт, зарядка

| Ключ                           | Ожидание (контракт)                                                                                                                                                                                                                                                                                                       | Факт в коде | Вердикт |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- | ------- |
| строка тренировок              | имя «Тренировки», под ним состав дня («силовая 45 мин · 1,9 т объёма»), справа сумма ккал 12,5 px/700. Тоннаж — фактический, по отмеченным подходам, без назначенного плана: день с планом обязан давать тот же тоннаж, что пустой. Плановый показывается только внутри карточки силовой                                  |             |         |
| назначенный план — «не начаты» | план до старта не даёт расхода, и ноль в строке читался бы как «тренировался и не потратил». Слово честнее числа                                                                                                                                                                                                          |             |         |
| строка быта                    | «60 мин · 126 ккал» — минуты и калории нетто, те же, что в разборе цели. Бейдж той же активности внутри карточки обязан показывать то же число. Расхождение нетто и брутто равно MET / (MET − 1) и у сущностей разное: у быта (MET 2,5) это 1,67 раза — самое грубое на экране, у зон тренировок от 1,2 (Z2) до 1,11 (Z4) |             |         |
| строка зарядки                 | «07:20 · 34 ккал» тоном --gr, когда была; «сделаю» — когда обещана; «не отмечено» — когда не решено. Зарядка не тип тренировки, а признак: она опознаётся источником записи, ярлыком «зарядка» или сигнатурой зон — и в строку тренировок не попадает, иначе двойной счёт                                                 |             |         |
