Здесь три других экрана, recreated из кода: 1a — ReportsTab, сводные таблицы недель шириной 1150px на экране 390px плюс сетка из десяти равнозначных спарклайнов; 1d — приём еды с тремя числовыми полями оценок; 1f — formula-card на одиннадцать строк.
