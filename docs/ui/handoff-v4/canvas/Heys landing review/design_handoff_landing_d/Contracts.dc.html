Значения живут здесь по одному разу — в атрибуте data-v, оттуда же рисуются. Курсивом под строкой — причина решения: воспроизводить не обязательно, переспаривать без причины не нужно. Проза на доске ревью может повторять числа; при расхождении верен этот файл и код.

Контракты пишутся по одному перед передачей блока — впрок они устаревают раньше, чем их прочитают. Кадры блоков помечены в сборке атрибутами data-screen-label и data-demo="stop"; по какому из них мерить — сказано в контракте блока. Разделы «Открыто до передачи» — то, что кодер не решает сам: пункт уходит оттуда, только когда решение написано текстом.

Общее Для страницы страничные константы

Константы страницы живут только здесь. Контракты блоков на них ссылаются словами, а не копируют значение — иначе при правке сетки придётся вспомнить про каждый блок.

Блочными остаются только те числа, которые у блоков разные: точка переключения раскладки, зазор карточек, положение фото.

Приёмка Лист по контракту 06 заполняет кодер

Одна строка проверки на каждую строку контракта. Значение брать из data-v, геометрию мерить в браузере по кадру «Тарифы · 390 · исправленный».

= совпало · ≠ расходится, вписать фактическое · — не реализовано · ? не проверить без решения дизайнера.

Строка ≠ закрывается либо правкой кода, либо правкой контракта — но не молча. По опыту трети расхождений виноват контракт, а не код.
