# Расхождения пакета и кода — читать до порта

Пакет описывает сборку версии D с нуля. Часть страницы уже реализована, и по
ряду пунктов код ушёл вперёд README. Ниже — где именно, и что считать истиной.

**Правило на время этого порта.** По пунктам из таблицы истина — **код и
`Тариф Pro - карточка.dc.html`**, не README и не `prototype.html`. По всему
остальному действует обычное правило: истина — прототип, расхождения реализации
считаются дефектами порта.

---

## 1. Тарифные карточки собраны отдельным файлом

`Тариф Pro - карточка.dc.html` лежит в этом же пакете. В нём четыре хода
исследования; **финальный — ряд из трёх карточек в секции «Три тарифа в языке
1a»** (Self · Pro · Pro Спорт) и карточка «Решения к порту» под ним с
обоснованием каждого пункта.

Что есть в этом файле и чего нет в README:

| Элемент | Где взять |
|---|---|
| числовая строка карточки (30 · ~1–2 ч · 4) | ряд «Три тарифа», карточка Pro |
| числовая строка Pro Спорт (4 · 45–60 · ∞) | ряд «Три тарифа», карточка Pro Спорт |
| списки с ведущим действием («**Заносит в дневник** всё, что вы прислали») | все три карточки |
| «Дополнительно к Pro» — фиолетовая пилюля вместо серой эйбровы «Сверх Pro» | карточка Pro Спорт |
| блок «После срыва — возвращает в ритм» | карточка Pro, между списком и «Итогом недели» |

Мобильные варианты карточки (ходы 1a / 1b / 1c) — **исследование, не спека**.
В 1a и 1c осталось «~90», оно снято; в подписи вариантов стоит пометка.

## 2. Числа и формулировки, изменённые после сборки пакета

| Пункт | В README | Истина |
|---|---|---|
| «~90 приёмов пищи» | есть в числовой строке | **снято**: объём задаёт клиент, а не сервис |
| ориентир ответа | «Ориентир первой реакции — 1–2 часа» | «~1–2 ч · ориентир ответа и записи», «ориентир» — ссылка на § 5.4 |
| часы сопровождения | «в дни и объёме выбранного тарифа» | **ежедневно, 09:00–21:00 МСК, включая выходные** (оферта 1.10, § 5.4) |
| время клиента | «обычно 3–5 минут в день» | **сверить с кодом**: там «до 3 минут». Победитель — код, число менялось по факту первых недель |
| карточки доверия | прежняя формулировка | «Порядок один у всех, выводы — нет» — из кода |
| Pro Спорт, состав | «Тренер ведёт…», «Тренер проверяет…» | подлежащее «тренер» убрано: читается второй исполнитель. УТП — специалист один |
| стартовая встреча | «цель, график и ограничения» | «цель, график и **что нужно учесть**» (§ 6.3: ограничения учитываем со слов клиента, а не оцениваем) |

## 4. Липкая пилюля — правило изменилось

Гаснет там, где в кадре есть собственный CTA секции: элементы с атрибутом
`data-own-cta` сверяются с вьюпортом, и пока хоть один пересекается — липкая
скрыта. Прежняя формулировка «скрыта на ≥861px» осталась верной, но она больше
не единственное условие. Размечены четыре кнопки: Self, Pro Спорт, кнопка
артефакта и заявка.

## 5. Что в пакете действительно новое

**Видео-демонстрация в герое.** Ролик (`ref/hero-curator-demo.mp4` + webm +
постер) и спека к нему: отбивки на 17.3 / 23.15 / 36.8 / 59.8 с, пропуск отрезка
2.62–3.98, кликабельные главы, проверка длительности на `loadedmetadata` —
не тот файл, отбивки и главы гаснут, видео играет как обычное. Тайминги вынести
в `public/hero-curator-demo.json`.

Сейчас в герое статичный мокап со скролл-зумом. Это отдельная работа, не часть
порта — делать её вместе с портом не нужно.
