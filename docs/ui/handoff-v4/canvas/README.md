# Канвасы UI v4 — актуальные макеты

Сюда складываются все канвасы дизайнера (`.dc.html`). Это **единственное
место**, где лежат актуальные макеты: если файл есть и здесь, и в `~/Downloads`,
верным считается тот, что здесь.

## Правила

**Класть новую версию поверх старой, с тем же именем.** История версий живёт в
git, а не в суффиксах `_v2`, `_final`, `_new` — иначе через неделю непонятно,
какой из трёх файлов свежий.

**После добавления обновить таблицу ниже** — дату и одну строку о том, что
внутри. По таблице ревьюер понимает, куда смотреть, не открывая 300-килобайтные
файлы.

**Не редактировать вручную.** Канвас — выгрузка из инструмента дизайнера; правки
делаются там и перевыгружаются сюда целиком.

**Архив:** функции, снятые с релиза, лежат в `canvas/archive/` (сейчас —
`Цикл v4.dc.html`, prompt-cycle-removal). Не брать их как актуальный макет.

## Как читать канвас без браузера

Файлы крупные, но текст из них достаём так:

```bash
python3 -c "
import re,sys,html
t=open(sys.argv[1],encoding='utf-8').read()
txt=re.sub(r'<(script|style)[^>]*>.*?</\1>','',t,flags=re.S)
txt=re.sub(r'<[^>]+>','\n',txt)
print('\n'.join(l for l in (html.unescape(x).strip() for x in txt.split('\n')) if l))
" "docs/ui/handoff-v4/canvas/ИМЯ.dc.html"
```

Проза решений — это строки длиннее 90 символов; подписи интерфейса короткие. Так
быстро отделяется «что решено» от «что нарисовано».
