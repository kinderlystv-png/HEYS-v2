# Очередь зон для сессии сведения

Файл существует ради одного: сессия Клода работает ходами и после коммита
останавливается, ожидая сообщения. Держать её занятой может только тот, кто шлёт
следующее сообщение. Чтобы будильник не будил без контекста, очередь лежит
здесь, а не в переписке.

**Правило: взял пункт — закрыл — перешёл к следующему, не спрашивая.**
Спрашивать диспетчера только если пункт упирается в решение владельца, в
дизайнерский вопрос или в занятый чужой файл.

**Зона считается закрытой**, когда `?` в её вердиктах не осталось, а остаток
объяснён `—` с `naKind`. Правка вида без вердиктов зону не закрывает.
