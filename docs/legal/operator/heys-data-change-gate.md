# HEYS · Data-change gate

Статус: R0 ready template. Использовать перед любой фичей, которая трогает
профиль, дневник, health-сигналы, лиды, платежи, аналитику, кураторский доступ
или интеграции.

## Pre-release строка

Перед релизом фичи в changelog/release review должна быть строка:

> ПДн data-change gate пройден: новых категорий ПДн / целей / получателей /
> сроков / трансграничной передачи нет; либо ссылки на обновлённые документы и
> blocking-задачи указаны.

## 5 вопросов

| Вопрос                                                    | Да/нет | Что сделать при «да»                                                    |
| --------------------------------------------------------- | ------ | ----------------------------------------------------------------------- |
| Добавляется новая категория ПДн или health-сущность?      |        | Обновить `heys-data-register.md`, privacy/health consent, проверить РКН |
| Меняется цель обработки?                                  |        | Обновить документы и РКН-драфт/изменение                                |
| Появляется новый получатель/обработчик?                   |        | Обновить access matrix/subprocessors, договор/поручение, документы      |
| Появляется зарубежный сервис или трансграничная передача? |        | Отдельная проверка ст. 12 152-ФЗ до включения                           |
| Меняются сроки хранения, доступы, логи или удаление?      |        | Обновить регламент, audit/delete flow, monthly audit checklist          |

## Решение по предтриальной анкете 2026-07-27

| Вопрос                                               | Ответ | Результат                                                                          |
| ---------------------------------------------------- | ----- | ---------------------------------------------------------------------------------- |
| Добавляется новая health-сущность?                   | Да    | реестр данных и health consent 1.5 обновлены                                       |
| Меняется цель обработки в сведениях РКН?             | Нет   | ручной отбор относится к уже опубликованным заявкам/триалам и сопровождению        |
| Появляется новый получатель/обработчик?              | Нет   | доступ только субъекту, назначенному куратору и оператору                          |
| Появляется трансграничная передача?                  | Нет   | анкета и ответы не передаются в мессенджеры/аналитику; БД Yandex Cloud РФ          |
| Меняются сроки хранения, доступы, логи или удаление? | Да    | отказанные анкеты — 30 дней; шифрование, session/ownership gate и read/write audit |

**Выход gate:** повторная подача изменения в РКН не требуется. Опубликованная
запись № 26-22-005319 уже охватывает заявки/триалы, сопровождение и специальную
категорию данных о здоровье; новые получатели, способы обработки и
трансграничная передача не появляются. Health consent 1.5, внутренний реестр,
шифрование, доступ и сроки хранения обновлены до начала обработки.
