# Правила общения в чате

> Памятка для пользователей тарифов Pro и Pro Спорт · обновлено 28 июля 2026 г.

---

## Как работает сопровождение

### 📱 Вы присылаете в чат:

- **Фото еды** — желательно на весах
- **Контекст** — если важно (стресс, праздник, кафе)
- **Вопросы** — любые по питанию и режиму

### ✅ Куратор:

- Вносит еду в ваш дневник
- Отвечает на вопросы
- Даёт рекомендации по питанию
- Поддерживает в сложных ситуациях

---

## Время работы

| Тариф         | Часы сопровождения | Формат вне созвонов                                        |
| ------------- | ------------------ | ---------------------------------------------------------- |
| **Pro**       | 09:00–21:00 МСК    | Сообщения по рабочему регламенту                           |
| **Pro Спорт** | 09:00–21:00 МСК    | Общий созвон раз в неделю + одна асинхронная корректировка |

**Ориентир первой реакции:** 1–2 часа в часы сопровождения. Это не
гарантированный SLA; полный разбор может потребовать больше времени. Pro Спорт
не означает круглосуточную или неограниченную связь.

## Как присылать еду

### ✅ Хорошо:

```
[Фото тарелки на весах]
Гречка + курица + овощи
```

### ✅ Ещё лучше:

```
[Фото на весах]
Творог 180г + гранола 24г
Перекус перед тренировкой
```

### ⚠️ Если без весов:

```
[Фото]
Примерно порция на ладонь
В кафе, весов нет
```

## Что можно спрашивать

✅ **Да:**

- Что поесть на ужин?
- Сколько калорий осталось?
- Можно ли это на дефиците?
- Как распределить еду перед тренировкой?
- Что делать, если хочется сладкого?

❌ **Куратор не отвечает на:**

- Медицинские вопросы («У меня болит живот»)
- Вопросы о лекарствах и БАДах
- Интерпретацию анализов

→ По этим темам: **обратитесь к врачу**

## Анти-срыв поддержка

Если чувствуете риск срыва:

1. **Напишите сразу** — не ждите
2. **Опишите ситуацию** — что происходит
3. **Куратор поможет** — найдём решение вместе

Пример:

```
⚠️ Сложный день, хочется всё съесть
Был конфликт на работе
```
