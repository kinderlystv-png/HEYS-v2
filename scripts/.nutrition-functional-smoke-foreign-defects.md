## clear_day + mergeDayData

**Наблюдение (2026-09-05):** после
`DayRealDataActions.applyDayStatusAction(day, 'clear_day')` локальный день имеет
`meals: []` и свежий `updatedAt`.
`mergeDayData(localCleared, staleRemote, { forceKeepAll: true })` всё равно
подтягивает `meals` из `staleRemote`, если у remote есть приёмы.

**Риск:** «Очистить день» в листе «вопрос о дате» может откатиться при синке со
устаревшим облаком.

**Владелец:** sync/merge (`heys_sync_merge_v1`), не `day/_meals.js`.

**Проверка:** симуляция в отклонённом тесте; не включено в smoke — GAP не в
инвентаре Task 52.
