# Согласие на доступ куратора

> **Версия:** 1.0 · **Дата:** 20 мая 2026 г.

Я разрешаю назначенному HEYS куратору просматривать данные моего профиля и
дневника в объёме, необходимом для сопровождения. Данные о здоровье доступны
только при наличии отдельного действующего согласия на их обработку. Доступ
можно отозвать в настройках; после отзыва сопровождение куратором прекращается.
