# Саммари книг: редакционный контракт

Каждая книга хранится как объект в `heys_reading_catalog_v1.js`. Интерфейс сам
выбирает единое оформление; в данных запрещены HTML, Markdown-разметка и готовые
CSS-классы.

## Обязательные поля

`id`, `title`, `author`, `year`, `verdict`, `practicalValue`, непустые `topics`,
`tags`, `coverTone`, `blocks` и `sources`. Идентификатор уникален, а все
источники используют HTTPS.

## Блоки

- `lead` — вводный тезис и общий вердикт;
- `heading` — смысловой раздел;
- `paragraph` — пересказ или анализ автора ревью;
- `quote` — только отделённая цитата с обязательным `attribution`;
- `example` — пример автора ревью с видимой подписью «Авторский пример»;
- `callout` — наблюдение с `tone`: `insight`, `practice` или `caution`;
- `list` — список с `items` и `ordered`;
- `verdict` — промежуточный или итоговый вывод.

Цитату, пересказ и авторский пример нельзя смешивать в одном блоке. Новые факты
и личный опыт рецензента не добавляются без подтверждённого источника; спорное
место помечается в исходнике для ручного заполнения и не публикуется как факт.
Пятиэтапный цикл или другая центральная модель объясняется один раз, а следующие
упоминания только ссылаются на неё.

Нельзя копировать крупные фрагменты оригинала: саммари пересказывает идеи своими
словами, а короткая цитата получает отдельный `quote` с атрибуцией.

## Добавление книги

```js
{
    id: 'stable-book-id',
    title: 'Название',
    author: 'Автор',
    year: 2026,
    verdict: 'Короткий вывод',
    practicalValue: 'Что читатель сможет применить',
    topics: ['Мышление'],
    tags: ['решения'],
    coverTone: 'violet',
    blocks: [
        { type: 'lead', text: 'Вводный тезис.' },
        { type: 'heading', text: 'Главная идея' },
        { type: 'paragraph', text: 'Пересказ идеи своими словами.' }
    ],
    sources: [{ label: 'Проверяемый источник', url: 'https://example.com/source' }]
}
```

## Редакторская проверка

Первые два смысловых блока дают ясный вердикт. В тексте есть отдельный ответ
«кому читать» и финальный ответ, стоит ли читать оригинал. До добавления книги
запустите `validateBookSummary(book, catalog)` и тест
`planning-reading.test.js`.
